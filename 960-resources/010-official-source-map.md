## Common Official Entry Points

- GitHub Credentials: https://learn.github.com/credentials
- GitHub Learning Catalog: https://learn.github.com/learning
- GitHub Docs: https://docs.github.com/
- Microsoft Learn Credentials: https://learn.microsoft.com/en-us/credentials/

## Study Guide 패턴 (Study Guide Pattern, SGP)

Microsoft Learn의 시험 Study Guide는 일반적으로 다음 패턴을 사용합니다.

```text
https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/<exam-code>
```

예: `gh-900`, `gh-200`, `gh-300`, `gh-100`, `gh-500`, `gh-600`.
