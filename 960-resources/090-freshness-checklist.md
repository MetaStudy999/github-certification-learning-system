# 090 Freshness Checklist — 최신성 점검

## 점검 시점

다음 시점마다 공식 정보를 다시 확인합니다.

1. 학습 시작
2. 각 과정 Final Review 시작
3. 시험 예약 직전
4. 시험 응시 직전
5. GitHub 제품·라이선스·기능명이 크게 변경된 경우
