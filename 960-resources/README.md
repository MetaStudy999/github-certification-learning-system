# 960 Resources — 공식 자료 Control Tower

GitHub 자격증 학습에 사용하는 **공식 Source of Truth**와 보조 자료를 통합 관리합니다.

## 빠른 시작 (Quick Start, QS)

1. [`010-official-source-map.md`](./010-official-source-map.md)에서 시험별 공식 Study Guide와 학습 페이지를 확인합니다.
2. 시험 범위는 Microsoft Learn/GitHub Learn의 최신 공식 페이지를 우선합니다.
3. 제품 동작은 GitHub Docs를 기준으로 확인합니다.
4. [`090-freshness-checklist.md`](./090-freshness-checklist.md)를 학습 시작·예약 전·응시 직전에 수행합니다.

## Source Priority

```text
Exam Study Guide / Certification Page
        ↓
GitHub Official Documentation
        ↓
GitHub Learn / Microsoft Learn Training
        ↓
GitHub Skills / Official Examples
        ↓
Community / Blog / Video (보조)
```

## 관리 원칙

- 공식 자료를 1차 근거로 사용합니다.
- 링크와 함께 `왜 보는가`, `어느 시험 Domain과 연결되는가`, `어떤 Lab과 연결되는가`를 기록합니다.
- 공식 원문 전체를 복제하지 않고 학습용 요약과 출처를 관리합니다.
- 변경 가능성이 있는 시험 정보는 확인 날짜를 남깁니다.
- 서로 다른 공식 페이지의 정보가 다르면 **시험 예약 화면과 최신 Study Guide를 최종 기준**으로 재검증합니다.
