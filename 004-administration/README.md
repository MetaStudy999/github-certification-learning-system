# 004 GitHub Administration

**Exam:** GH-100  
**Status:** PLANNED

## Quick Start

1. Enterprise, Organization, Team, Repository 계층을 이해합니다.
2. Role, Permission, Policy를 학습합니다.
3. Authentication, Authorization, SSO, SAML, SCIM을 정리합니다.
4. Ruleset, Branch Protection, Audit Log를 실습 관점에서 이해합니다.
5. 가상의 기업 GitHub 운영 정책을 설계합니다.

## 핵심 영역

- Enterprise / Organization 관리
- Team / Role / Permission
- Repository Governance
- Authentication / Authorization
- SSO / SAML / SCIM
- Ruleset / Branch Protection
- Audit / Policy / Enterprise Operations

## 대표 프로젝트

가상의 기업을 기준으로 Organization, Team, Repository, 사용자 권한과 정책을 설계한 Enterprise Administration Blueprint를 작성합니다.
