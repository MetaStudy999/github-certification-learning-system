# 090 Audit, Usage, 비용 — Q081–Q090 (090 Audit, Usage, Cost — Q081–Q090, AUCQ081Q090)

## Q081
"누가 Organization 설정을 변경했는가"를 조사하는 데 가장 적절한 자료는?

A. Audit Log  B. README  C. Wiki  D. Repository Topic

**정답: A** — 관리 이벤트 추적의 핵심 자료입니다.

## Q082
Audit Log를 운영할 때 가장 중요한 관점은?

A. Actor·Action·Target·Time·Scope  B. Emoji  C. Star  D. Fork

**정답: A** — 이벤트 주체와 대상·시점을 구조적으로 봅니다.

## Q083
Actions 비용 급증을 분석할 때 가장 직접적인 원인은?

A. Workflow 실행량·Runner 사용·Artifact/Storage  B. Issue Label  C. README  D. Team 이름

**정답: A** — Metered Usage의 주요 동인을 확인합니다.

## Q084
License 활용률을 계산하려면 무엇을 비교해야 하는가?

A. 할당 사용자와 실제 활성 사용자  B. Commit과 PR  C. Star와 Fork  D. Issue와 Discussion

**정답: A** — 배정 대비 실제 사용을 봅니다.

## Q085
API 사용량이 급증하고 자동화 오류가 발생한다. FIRST로 할 일은?

A. 호출 주체·Endpoint·빈도·Rate Limit 확인  B. Repo Public 전환  C. Audit 삭제  D. 모든 Token 확대

**정답: A** — Usage Pattern을 먼저 확인합니다.

## Q086
비용 최적화의 가장 좋은 순서는?

A. 측정 → 원인 분류 → 우선순위 → 조치 → 재측정  B. 무조건 기능 중지  C. 로그 삭제  D. 사용자 전원 삭제

**정답: A** — 데이터 기반 최적화가 필요합니다.

## Q087
정책 변경 직후 Workflow 실패율이 증가했다. 어떤 자료를 결합해야 하는가?

A. Audit Log + Workflow Run Trend  B. README + Wiki  C. Star + Fork  D. Avatar + Bio

**정답: A** — Change와 Operational Signal을 연결합니다.

## Q088
월간 Enterprise Review에서 가장 적절하지 않은 지표는?

A. Security Alert Trend  B. Actions Usage  C. License Utilization  D. 개인 Password 목록

**정답: D** — Credential 원문은 관리 지표가 아닙니다.

## Q089
비활성 계정 정리 후 반드시 확인할 것은?

A. 업무 소유권·Repository 접근·Automation 영향  B. Star 수  C. Avatar  D. README 길이

**정답: A** — Offboarding이 서비스 연속성을 해치지 않아야 합니다.

## Q090
비용·사용량 보고서에 가장 필요한 정보는?

A. 기간·Scope·Baseline·Trend·Action  B. 개인 Token  C. SSH Key  D. Password

**정답: A** — 분석 가능하고 재검증 가능한 형식으로 기록합니다.
