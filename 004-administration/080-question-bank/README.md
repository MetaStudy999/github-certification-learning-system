## Gate

- 1회차: **80/100 이상**
- 2회차: **85/100 이상**
- 오답 재시험: **90% 이상**

## 문제 설계 원칙

- Enterprise / Organization / Repository Scope를 구분합니다.
- Identity, Security, Actions, Audit, Cost를 Scenario로 연결합니다.
- `BEST`, `MOST appropriate`, `FIRST` 유형의 판단을 연습합니다.
- 실제 Production 정책을 약화시키는 행동을 정답으로 요구하지 않습니다.
