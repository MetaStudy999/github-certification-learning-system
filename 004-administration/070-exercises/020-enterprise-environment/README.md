# 020 Enterprise Environment — 수행형 연습

## E020-01 — Deployment Decision
GHEC+EMU, GHEC+Data Residency+EMU, GHEC+Personal Accounts, GHES 네 모델의 선택 기준을 표로 작성하세요.

## E020-02 — Cloud + Managed Identity
Cloud를 사용하면서 기업이 업무 계정 수명주기를 통제하려는 조직의 후보 모델과 선택 근거를 적으세요.

## E020-03 — Data Residency
특정 지역의 데이터 저장 요구사항이 있는 Cloud 조직에서 추가 확인할 항목을 Identity, Compliance, Operations 관점에서 작성하세요.

## E020-04 — GHES Responsibility
GHES를 선택했을 때 조직이 맡게 되는 Infrastructure, Upgrade, Backup, Monitoring, Network 책임을 설명하세요.

## E020-05 — Admin vs Support
다음 문제를 `Admin`, `Support`, `Investigate first`로 분류하세요.
- Role 설정 오류
- Runner Label 오류
- GitHub 서비스 자체 장애 의심
- GHES 내부 서비스 오류가 Diagnostics 이후 지속

## E020-06 — Support Bundle
Support Bundle의 목적, 생성 시점, 취급 시 주의할 민감정보 위험을 작성하세요.

## E020-07 — Developer Standards
Branching, PR Review, Required Check, Release의 조직 표준 초안을 작성하세요.

## E020-08 — License Consumption
License Entitlement와 실제 Consumption의 차이를 설명하고 과다 할당을 찾는 방법을 작성하세요.

## E020-09 — Billing Scenario
사용량 기반 제품 비용이 급증했습니다. 어떤 Report와 Owner를 확인하고 어떤 순서로 원인을 분석할지 작성하세요.

## E020-10 — Deployment Defense
`GHES가 가장 통제력이 높으므로 모든 기업에 최선이다`라는 주장에 운영비·업그레이드·지원·Cloud 장점 관점에서 반박하세요.
