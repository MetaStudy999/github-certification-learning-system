## 시험 방법

1. `questions.md`만 엽니다.
2. 100분보다 짧은 **60분 제한**으로 40문항을 풉니다.
3. 답을 확정한 뒤 `answers.md`를 확인합니다.
4. 틀린 문제는 `120-wrong-answers/`에 기록합니다.
5. 약점 Lab을 재수행합니다.
6. 최소 하루 후 다음 Mock을 풉니다.

