## Evidence 원칙

- 실제 Password, Token, Secret, SSH Private Key를 기록하지 않습니다.
- Production 보안 설정을 학습 목적으로 약화시키지 않습니다.
- 가능한 경우 Screenshot보다 **재현 가능한 설정 설명과 URL/Log ID**를 함께 남깁니다.
- 개인정보나 조직의 민감 운영정보는 공개 Repository에 기록하지 않습니다.
