## Stale 콘텐츠 규칙 (Stale Content Rule, SCR)

다음 자료는 특히 주의합니다.

- 2026년 7월 이전 GH-100 Domain 표
- 오래된 Enterprise licensing 설명
- EMU / Data Residency 도입 이전 비교 자료
