# 090 Exam Readiness Policy — 시험 준비도 정책

## 목적

시험 날짜가 왔다는 이유만으로 응시하지 않고, **공식 범위 확인 + 학습 + 실습 + 문제풀이 + Mock + 오답 재시험**을 모두 근거로 판단합니다.

## Minimum Gate

- [ ] 최신 공식 Study Guide 확인
- [ ] 핵심 용어 90% 이상 설명 가능
- [ ] 핵심 Labs 80% 이상 수행
- [ ] QBank 2회차 85% 이상
- [ ] 최근 Mock 2회 연속 85% 이상
- [ ] 최근 오답 Retry 90% 이상

## Conservative Gate — 권장

- [ ] Mock 01 85% 이상
- [ ] Mock 02 85% 이상
- [ ] Final Mock 90% 이상
- [ ] 즉, 세 번의 Mock 모두 85% 이상
- [ ] 취약 Domain이 반복되지 않음
- [ ] 공식 시험 범위·언어·시간·가격을 예약 직전 다시 확인

## 판정

```text
Minimum Gate 미달
→ REVIEW / NOT READY

Minimum Gate 충족
→ GATE-CANDIDATE

Conservative Gate 충족
→ EXAM-READY 권장
```

## 주의

`CONTENT-READY`는 Repository에 학습 자료가 준비되었다는 의미이고, `EXAM-READY`는 실제 학습자의 시험 준비도가 검증되었다는 의미입니다.
