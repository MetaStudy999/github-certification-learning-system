# 090 Study Cycle — QBank에서 Mock까지

## Standard 흐름 (Standard Flow, SF)

```text
100문제 1회차
→ 80% Gate
→ 오답 분류
→ 관련 Terms / Concepts / Lab 복습
→ 100문제 2회차
→ 85% Gate
→ 최근 오답 Retry 90%+
→ Mock 01
→ Mock 02
→ Final Mock
→ Exam Readiness 판단
```

## 실패 시 분기

| 결과 | 다음 행동 |
|---|---|
| QBank <70% | Terms + Concepts 재학습 |
| QBank 70–79% | 관련 Exercise + Lab 재수행 |
| QBank 80–84% | 오답 중심 재학습 후 2회차 |
| QBank 85%+ | Mock 단계 진입 가능 |
| Retry <90% | 해당 Error Code 영역 재학습 |
