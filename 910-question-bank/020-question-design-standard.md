## Difficulty Model

| 등급 | 의미 |
|---|---|
| L1 | 용어·기본 기능 식별 |
| L2 | 유사 개념 비교 |
| L3 | 단일 Scenario에서 기능 선택 |
| L4 | Scope·권한·보안·운영 조건이 결합된 Scenario |
| L5 | 여러 대안 중 최선의 설계·운영 선택 판단 |

## Quality Gate

문제를 추가하기 전에 다음을 확인합니다.

- [ ] 공식 시험 목표와 연결되는가?
- [ ] 정답 근거를 공식 문서로 검증할 수 있는가?
- [ ] 다른 선택지가 왜 덜 적절한지 설명 가능한가?
- [ ] 암기만이 아니라 판단을 요구하는가?
- [ ] 실제 시험 문항을 기억해 재현한 것이 아닌가?
- [ ] 기능명·정책명이 최신인지 확인했는가?
- [ ] 위험한 운영 변경을 요구하지 않는가?

## Naming

개별 파일형 문제를 추가할 경우 `Q-001-001.md`처럼 `과정-세트-문항`을 추적할 수 있는 ID를 사용합니다.
