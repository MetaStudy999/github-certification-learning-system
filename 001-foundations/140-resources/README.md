## 자료 평가 기준

새 자료를 추가할 때 다음을 확인합니다.

- [ ] 공식 시험 범위와 직접 관련되는가?
- [ ] 2026년 현재 기능과 맞는가?
- [ ] 설명만이 아니라 실습으로 연결되는가?
- [ ] 출처와 URL이 명확한가?
- [ ] 실제 시험 문제 유출 자료가 아닌가?

## 추천 사용법

시험 직전에는 자료 수를 늘리지 않습니다.

```text
공식 Study Guide
+ 이 Repository의 Terms
+ Concepts
+ Wrong Answers
+ Final Review
```

만 반복하는 것을 우선합니다.
