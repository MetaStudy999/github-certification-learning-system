# 010 Overview — GH-900 시험 개요

## Quick Start

이 문서는 GitHub Foundations 시험에서 **무엇을, 어느 비중으로, 어떤 순서로 공부할지** 정리합니다.

## 시험 개요

- **Certification:** GitHub Foundations
- **Exam:** GH-900
- **Level:** Beginner (입문)
- **Duration:** 100 minutes (100분)
- **Passing score:** Microsoft 인증 시험 기준 700점 이상
- **Languages:** English, Spanish, Portuguese (Brazil), Korean, Japanese
- **Baseline price:** USD 99, 지역별 가격 변동 가능

## 2026년 시험 Domain

| # | Domain | 비중 | Fast Track 우선도 |
|---:|---|---:|---|
| 1 | Understand Git and GitHub basics | 25–30% | 최우선 |
| 2 | Work with GitHub repositories | 10–15% | 높음 |
| 3 | Collaborate using GitHub | 10–15% | 높음 |
| 4 | Apply modern development practices | 10–15% | 높음 |
| 5 | Manage projects with GitHub | 5–10% | 중간 |
| 6 | Understand privacy, security, and administration | 10–15% | 높음 |
| 7 | Explore the GitHub community | 5–10% | 중간 |

## Domain 1 — Git과 GitHub 기본

반드시 설명할 수 있어야 합니다.

- Version Control (버전 관리)의 목적과 이점
- Git과 GitHub의 차이
- Repository, Commit, Branch
- GitHub Account / Organization / Enterprise의 차이
- GitHub Flow
- Markdown의 기본 사용 목적
- GitHub Desktop / GitHub Mobile 사용 상황

## Domain 2 — Repository 작업

- README, LICENSE, CONTRIBUTING, CODEOWNERS, SECURITY
- Repository 생성·구성·유지
- Template과 Branch 활용
- 파일 관리
- Insights, Stars, Metrics, Dependency 관련 정보
- Repository 유지관리 Best Practice

## Domain 3 — Collaboration

- Issues
- Pull Requests (PR)
- Discussions
- Notifications
- PR과 Issue 연결
- Template / Filter / Assignment
- Gists / Wikis / GitHub Pages

## Domain 4 — Modern Development

- GitHub Actions의 목적
- GitHub Copilot의 역할
- Copilot Agent / Agent Mode / Multi-model 개념
- Copilot plan 차이의 기본 개념
- GitHub Codespaces
- Dev Container
- Project Insights

## Domain 5 — Project Management

- GitHub Projects
- Issue와 PR을 이용한 작업 추적
- Views / Fields / Filters
- 진행 상태와 협업 가시성

## Domain 6 — Privacy, Security, Administration

- Two-Factor Authentication, 2FA (2단계 인증)
- Passkey (패스키)
- Repository / Organization Role과 Permission
- Enterprise Managed Users, EMU
- Repository Visibility
- Branch Protection
- Organization / Team / Role 기본

## Domain 7 — GitHub Community

- Open Source (오픈 소스)의 장점
- GitHub Sponsors
- Follow
- GitHub Marketplace
- InnerSource
- Fork / Template / Discoverability
