# 040 Official Docs — 공식 문서 기준

## Quick Start

GitHub Foundations는 **공식 Study Guide를 시험 범위의 기준선(Baseline)** 으로 사용합니다. 블로그·덤프·요약집보다 공식 문서를 우선합니다.

## 1. 최우선 공식 자료

### A. GH-900 Study Guide

- Microsoft Learn — Study guide for Exam GH-900: GitHub Foundations
- https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-900

확인할 항목:

- 최신 Skills measured
- Domain 비중
- Change log
- 추천 Learning Path

### B. GitHub Foundations Certification

- https://learn.microsoft.com/en-us/credentials/certifications/github-foundations/

확인할 항목:

- 시험 시간
- 응시 언어
- 가격
- Practice Assessment
- Exam Sandbox

### C. GitHub Certifications 소개

- https://docs.github.com/en/get-started/showcase-your-expertise-with-github-certifications/about-github-certifications

## 2. Domain별 공식 문서 학습 지도

| Domain | 우선 학습 주제 |
|---|---|
| 1. Git/GitHub basics | Git 기본, GitHub Flow, Markdown, 계정 유형 |
| 2. Repositories | Repository, Branch, 파일·문서, Insights |
| 3. Collaboration | Issues, PR, Discussions, Notifications, Gist/Wiki/Pages |
| 4. Modern development | Actions, Copilot, Codespaces, Dev Containers |
| 5. Projects | GitHub Projects, Views, Fields, Filters |
| 6. Privacy/Security/Admin | 2FA, Passkey, Roles, Permissions, Visibility, Branch Protection |
| 7. Community | Open Source, Sponsors, Marketplace, InnerSource, Fork/Template |

## 4. 공식문서 학습 기록 형식

각 문서를 읽을 때 다음 5가지만 기록합니다.

```text
1. 문서 제목
2. 핵심 개념 3개
3. 시험에서 헷갈릴 비교 1개
4. 직접 해볼 실습 1개
5. 다시 확인할 공식 URL
```

이 Repository의 Question Bank와 Mock Exam은 **공식 시험 문제 복제물이 아니라 학습목표를 기반으로 자체 작성한 문제**만 사용합니다.
