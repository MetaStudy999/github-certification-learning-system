# 020 연습문제 (Exercise, EXR) — 저장소 (Repositories, R)

## 목표

Repository 생성·복제·문서화·공개 범위와 Fork/Clone의 차이를 구분합니다.

## 문제

1. 새 Repository를 만들 때 README를 함께 생성하는 장점을 설명하세요.
2. `README.md`, `LICENSE`, `CONTRIBUTING.md`, `SECURITY.md`, `CODEOWNERS`의 역할을 각각 한 줄로 적으세요.
3. **Clone**과 **Fork**가 각각 적합한 상황을 하나씩 작성하세요.
4. Public Repository와 Private Repository의 차이를 설명하세요.
5. Remote 이름 `origin`은 무엇을 의미하는지 설명하세요.
6. `git remote -v`로 무엇을 확인할 수 있나요?
7. 팀 Repository에 Write 권한이 있다면 Fork 없이도 작업할 수 있는 일반적인 이유를 설명하세요.
8. 오픈소스 프로젝트의 사용·수정·배포 조건을 확인할 때 가장 먼저 볼 파일은 무엇인가요?
9. 보안 취약점을 공개 Issue가 아니라 정해진 신고 절차로 제보하도록 안내하려면 어떤 문서가 필요하나요?
10. 특정 디렉터리 변경 시 Review 책임자를 지정하는 데 사용할 수 있는 파일은 무엇인가요?

## 시나리오 (Scenario, SCN)

다음 상황에 적합한 선택을 적으세요.

> 외부 공개 프로젝트에 코드 한 줄을 수정해 기여하고 싶지만 원본 Repository에 Write 권한이 없습니다.

필수 포함 항목:

```text
Fork
Clone
Branch
Commit
Push
Pull Request
```

## 완료 기준

- [ ] Repository 핵심 문서 5개의 역할 설명
- [ ] Clone vs Fork를 권한·기여 흐름 관점에서 구분
- [ ] Public / Private 차이 설명
- [ ] Scenario 흐름을 자료 없이 작성
