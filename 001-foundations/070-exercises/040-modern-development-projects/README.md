# 040 연습문제 (Exercise, EXR) — 현대적 개발 와 프로젝트 (Modern Development & Projects, MDP)

## 목표

GitHub Actions, Copilot, Codespaces, Projects의 목적을 구분하고 상황에 맞는 기능을 선택합니다.

## 문제

1. Push마다 Test를 자동 실행할 때 가장 적합한 GitHub 기능은 무엇인가요?
2. 브라우저에서 사전 구성된 개발환경을 시작할 때 적합한 기능은 무엇인가요?
3. AI를 이용해 코드 설명·보완·테스트 아이디어를 얻는 기능은 무엇인가요?
4. Issue와 PR을 Board/Table 형태로 추적하는 기능은 무엇인가요?
5. GitHub Actions에서 Event, Workflow, Job, Step의 관계를 간단히 설명하세요.
6. Codespaces가 Local 환경 차이 문제를 줄이는 데 도움이 되는 이유를 설명하세요.
7. Copilot이 제안한 코드를 사람이 검토해야 하는 이유를 2가지 적으세요.
8. GitHub Projects의 Field와 View는 각각 어떤 역할을 하나요?
9. 자동화가 필요한 작업과 사람이 판단해야 하는 작업을 각각 하나씩 예시로 적으세요.
10. 다음 상황에 적합한 기능을 각각 선택하세요: `Actions`, `Copilot`, `Codespaces`, `Projects`.

   - 반복 Test 자동화
   - AI 코드 보조
   - Cloud 개발환경
   - 작업 진행률 관리

## 시나리오 (Scenario, SCN)

> 신규 팀원이 프로젝트에 참여합니다. 개발환경 설정 시간을 줄이고, PR이 올라오면 자동으로 Test하며, 전체 작업 진행률을 한 화면에서 보고 싶습니다.

어떤 GitHub 기능 조합을 사용할지 이유와 함께 설명하세요.

## 완료 기준

- [ ] Actions / Copilot / Codespaces / Projects 역할을 혼동하지 않음
- [ ] Workflow 계층을 설명 가능
- [ ] 자동화와 인간 검토의 역할을 구분 가능
