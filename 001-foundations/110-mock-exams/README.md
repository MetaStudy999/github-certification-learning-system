# 110 Mock Exams — 모의고사

## 목적

실제 GH-900 문항을 복제하지 않고, 공식 Domain 비중을 참고해 **자체 모의고사**를 구성합니다.

## 권장 구성

한 회차당 40문항을 권장합니다.

| Domain | 권장 문항 수(40문항 기준) |
|---|---:|
| Git and GitHub basics | 11 |
| Repositories | 5 |
| Collaboration | 5 |
| Modern development | 5 |
| Projects | 3 |
| Privacy/Security/Admin | 7 |
| Community | 4 |

> 실제 시험 비중은 범위이므로 모의고사 문항 수는 근사치입니다.

## Mock 순서

```text
Mock 01 → 진단
   ↓
오답 분류
   ↓
약점 Lab
   ↓
Mock 02 → 응시 Gate
   ↓
오답 재시험
   ↓
Final Mock
```

## 점수 기준

| 정답률 | 판정 | 행동 |
|---:|---|---|
| 90%+ | EXAM-READY | 최종 오답만 복습 |
| 85–89% | READY | 1회 추가 확인 |
| 75–84% | REVIEW | 약점 Domain 재학습 |
| <75% | NOT READY | Terms/Concepts/Labs 재수행 |

## Exam Gate

**최근 2회 연속 85% 이상**을 권장 응시 기준으로 사용합니다.
