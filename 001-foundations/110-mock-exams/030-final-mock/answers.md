# Final Mock — 정답 Key (Final Mock — Answer Key, FMAK)

| Q | Answer | 핵심 이유 |
|---:|:---:|---|
| 01 | A | Git은 Local에서도 동작하는 분산 버전 관리 시스템입니다. |
| 02 | A | GitHub는 Repository 호스팅과 PR/Issue 협업 플랫폼입니다. |
| 03 | A | `git add`는 변경을 Staging Area에 올립니다. |
| 04 | A | `git fetch`는 Remote 정보를 가져오되 자동 통합하지 않습니다. |
| 05 | A | 같은 Repository의 독립 작업에는 Branch가 적합합니다. |
| 06 | A | Write 권한 없는 공개 저장소 기여는 일반적으로 Fork로 시작합니다. |
| 07 | A | PR 전 목적과 대상 Branch를 확인해야 잘못된 변경 제안을 줄일 수 있습니다. |
| 08 | A | Reviewer는 PR 변경 내용을 검토합니다. |
| 09 | A | Assignee는 작업 담당자 지정에 사용됩니다. |
| 10 | A | Label은 Issue/PR 분류에 사용됩니다. |
| 11 | A | Milestone은 여러 Issue/PR을 목표 단위로 묶습니다. |
| 12 | A | Discussions는 장기 토론·Q&A·아이디어 수렴에 적합합니다. |
| 13 | A | README는 프로젝트 목적과 사용법을 안내합니다. |
| 14 | A | LICENSE는 사용·수정·재배포 조건을 명시합니다. |
| 15 | A | CONTRIBUTING은 기여 절차와 규칙을 안내합니다. |
| 16 | A | SECURITY는 취약점 신고 정책을 안내합니다. |
| 17 | A | CODEOWNERS는 경로별 Review 책임자를 지정합니다. |
| 18 | A | Actions는 Event 기반 자동화에 사용됩니다. |
| 19 | A | Runner는 Job 실행 환경입니다. |
| 20 | A | Codespaces는 Cloud 개발환경을 제공합니다. |
| 21 | A | Copilot은 AI 기반 개발 보조 기능입니다. |
| 22 | A | Projects는 Issue/PR 계획과 추적에 사용됩니다. |
| 23 | A | Field는 Project 사용자 정의 속성을 관리합니다. |
| 24 | A | 보호 규칙으로 Review/Check 요구 조건을 설정할 수 있습니다. |
| 25 | A | 2FA/Passkey는 인증 보안을 강화합니다. |
| 26 | A | Team은 Organization 구성원을 그룹화해 권한을 관리합니다. |
| 27 | A | Enterprise는 여러 Organization을 상위에서 관리합니다. |
| 28 | A | Visibility와 Permission이 접근 범위를 직접 결정합니다. |
| 29 | A | Template Repository는 표준 구조의 새 프로젝트 시작에 적합합니다. |
| 30 | A | Fork는 원본에 기여하기 위한 별도 Repository 복제에 적합합니다. |
| 31 | A | InnerSource는 조직 내부에 오픈소스 협업 방식을 적용합니다. |
| 32 | A | Star는 관심 표시·북마크 성격입니다. |
| 33 | A | Watch는 Repository 활동 알림 구독에 관련됩니다. |
| 34 | A | Marketplace는 GitHub 확장 기능을 찾는 곳입니다. |
| 35 | A | Sponsors는 오픈소스 후원에 사용됩니다. |
| 36 | A | Issue→Branch→Commit→Push→PR→Review/Checks→Merge가 일반적 흐름입니다. |
| 37 | A | Pull은 가져오기와 통합을 함께 수행합니다. |
| 38 | A | Clone=Local 복제, Fork=GitHub 상 별도 Repository 복제입니다. |
| 39 | A | Actions=자동화, Copilot=AI 보조, Codespaces=Cloud IDE입니다. |
| 40 | A | 시험 직전에는 새 범위보다 최근 오답과 비교 개념 복습이 효율적입니다. |
