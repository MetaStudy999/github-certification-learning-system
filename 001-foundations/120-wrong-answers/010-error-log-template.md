# 010 Error Log Template — 오답 기록 템플릿

문제 하나를 틀릴 때마다 아래 형식을 복사해 기록합니다.

```text
ID:
Source: Question Bank / Mock 01 / Mock 02 / Final Mock
Date:
Domain:
Question summary:
My answer:
Correct answer:
Error code: CONCEPT / COMPARE / READING / MEMORY / PRACTICE / SCOPE
Why I was wrong:
Correct concept in one sentence:
Why the other choices are wrong:
Official source:
Related lab:
Retry date +1 day:
Retry result:
Retry date +7 days:
Retry result:
```

## 기록 원칙

1. 정답만 적지 않습니다.
2. `왜 틀렸는지`를 한 문장으로 명확히 씁니다.
3. 관련 Lab이 있으면 다시 수행합니다.
4. 같은 개념을 두 번 이상 틀리면 `HIGH` 우선순위로 올립니다.
5. `COMPARE` 오류는 `090-final-review/020-confusion-matrix.md`에 추가합니다.
