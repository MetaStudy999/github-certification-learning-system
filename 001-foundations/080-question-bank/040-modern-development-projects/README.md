# 040 문제 세트 (Question Set, QS) — 현대적 개발 와 프로젝트 (Modern Development & Projects, MDP) (Q031–Q040)

## Q031
Push 시마다 자동으로 Test를 실행하려고 한다. 가장 적합한 GitHub 기능은?

A. GitHub Actions  
B. GitHub Pages  
C. GitHub Sponsors  
D. GitHub Discussions

<details><summary>정답 및 해설</summary>

**정답: A** — GitHub Actions는 Event 기반 Workflow 자동화에 사용됩니다.
</details>

## Q032
브라우저에서 사전 구성된 개발환경을 빠르게 시작하려고 한다. 가장 적합한 기능은?

A. Codespaces  
B. Projects  
C. Issues  
D. Releases

<details><summary>정답 및 해설</summary>

**정답: A** — Codespaces는 Cloud 기반 개발환경을 제공합니다.
</details>

## Q033
AI를 활용해 코드 설명과 수정 아이디어, 테스트 초안을 얻으려 한다. 가장 관련 있는 기능은?

A. GitHub Copilot  
B. GitHub Pages  
C. Milestones  
D. Discussions

<details><summary>정답 및 해설</summary>

**정답: A** — Copilot은 AI 기반 개발 보조 기능을 제공합니다.
</details>

## Q034
Issue와 Pull Request를 Board 또는 Table 형태로 추적하려고 한다. 가장 적합한 기능은?

A. GitHub Projects  
B. GitHub Pages  
C. GitHub Sponsors  
D. Gist

<details><summary>정답 및 해설</summary>

**정답: A**
</details>

## Q035
GitHub Actions의 계층을 가장 잘 나타낸 것은?

A. Workflow → Job → Step  
B. Step → Repository → Account  
C. Branch → Account → Workflow  
D. Issue → License → Step

<details><summary>정답 및 해설</summary>

**정답: A** — Workflow 안에 하나 이상의 Job이 있고, 각 Job은 Step들로 구성될 수 있습니다.
</details>

## Q036
GitHub Actions에서 Workflow 실행을 시작하게 만드는 Push, Pull Request 같은 조건을 무엇이라고 보는 것이 가장 적절한가?

A. Event/Trigger  
B. License  
C. Milestone  
D. Fork owner

<details><summary>정답 및 해설</summary>

**정답: A** — 특정 Event가 Workflow 실행을 유발합니다.
</details>

## Q037
Codespaces의 장점으로 가장 적절한 것은?

A. 모든 Repository를 자동 Public으로 만든다.  
B. 팀원이 비교적 일관된 Cloud 개발환경에서 빠르게 시작하도록 도울 수 있다.  
C. Pull Request Review를 제거한다.  
D. Git Commit 이력을 삭제한다.

<details><summary>정답 및 해설</summary>

**정답: B**
</details>

## Q038
Copilot이 생성한 코드에 대해 개발자가 해야 할 태도로 가장 적절한 것은?

A. 항상 정확하므로 검토 없이 사용  
B. 코드의 정확성·보안·라이선스·프로젝트 맥락을 사람이 검토  
C. 모든 Test를 제거  
D. 원본 코드와 상관없이 자동 Merge

<details><summary>정답 및 해설</summary>

**정답: B** — AI 제안은 보조 수단이며 사람의 검토와 테스트가 필요합니다.
</details>

## Q039
GitHub Projects에서 작업 항목을 상태, 우선순위, 담당 영역 등으로 관리하는 데 도움이 되는 것은?

A. Fields  
B. SSH key만  
C. LICENSE만  
D. Releases만

<details><summary>정답 및 해설</summary>

**정답: A** — Custom Field 등을 통해 작업 항목에 구조화된 속성을 부여할 수 있습니다.
</details>

## Q040
신규 팀원의 환경 설정 시간을 줄이고, PR마다 자동 Test하며, 전체 작업 상황을 추적하려 한다. 가장 적절한 조합은?

A. Codespaces + Actions + Projects  
B. Pages + Sponsors + Stars  
C. Gist + Watch + Follow  
D. Releases + License + Fork만

<details><summary>정답 및 해설</summary>

**정답: A** — Codespaces는 개발환경, Actions는 자동화, Projects는 작업 관리를 담당합니다.
</details>
