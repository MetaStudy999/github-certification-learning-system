# 090 Products & Community — Q081–Q090

> GH-900 학습목표 기반 자체 제작 문제입니다.

### Q081
Push 시 자동 테스트를 실행하려면?
A. GitHub Actions  
B. GitHub Pages  
C. GitHub Sponsors  
D. Discussions

<details><summary>정답</summary>

**A** — Actions는 Event 기반 Workflow 자동화에 사용됩니다.
</details>

### Q082
브라우저에서 사전 구성된 개발환경을 사용하려면?
A. Codespaces  
B. Projects  
C. Wiki  
D. Marketplace

<details><summary>정답</summary>

**A** — Codespaces는 Cloud 개발환경을 제공합니다.
</details>

### Q083
AI에게 코드 설명과 테스트 초안을 요청하려면?
A. Copilot  
B. Actions  
C. Pages  
D. Sponsors

<details><summary>정답</summary>

**A** — Copilot은 AI 기반 개발 보조 기능입니다.
</details>

### Q084
Issue와 PR을 Board/Table/Roadmap 형태로 관리하려면?
A. Projects  
B. Gist  
C. Sponsors  
D. Pages

<details><summary>정답</summary>

</details>

### Q085
정적 웹사이트를 Repository 기반으로 게시하려면?
A. Pages  
B. Discussions

D. Milestone

</details>

### Q086
오픈소스 협업 방식을 회사 내부에 적용하는 것은?
A. InnerSource  
B. Codespaces

</details>

### Q087
관심 있는 Repository를 표시하고 나중에 찾기 쉽게 하는 기능은?

</details>

### Q088

### Q089
