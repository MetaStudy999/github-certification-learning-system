# 020 실습 증빙 템플릿 (Lab Evidence Template, LET)

## 실습 기록 (Lab Record, LR)

```text
Date:
Lab code:
Lab title:
Environment:
Goal:
```

## 액션 Performed (Actions Performed, AP)

```text
Commands / GitHub actions:
1.

```

## 검증 (Verification, VER)

```text
Expected result:
Actual result:
PASS / FAIL:
How verified:
```

## GitHub 참고자료 (GitHub References, GHR)

```text
Repository URL:
Issue URL:
Pull Request URL:
Commit URL:
Project URL:
```

## 학습 참고 (Learning Note, LN)

```text
One-sentence concept:
What I confused:
How I fixed it:

```

## 증빙 점검표 (Evidence Checklist, EC)

- [ ] 명령 또는 GitHub 작업을 직접 수행했다.
- [ ] 결과를 확인했다.
- [ ] 실패한 경우 원인과 해결 과정을 기록했다.
- [ ] 민감정보가 포함되지 않았다.
- [ ] 관련 Lab 또는 Domain과 연결했다.
