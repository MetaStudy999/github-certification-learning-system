# 150 Evidence — 학습·실습 증거 기록

## 목적

자격증 합격 여부뿐 아니라 **무엇을 직접 수행했고 설명할 수 있는지** 남깁니다.

## Evidence 종류

| 코드 | Evidence | 예시 |
|---:|---|---|
| 010 | Environment | OS, Git Version, 도구 |
| 020 | Git Labs | `git log`, Branch 흐름 |
| 030 | GitHub Flow | Issue/PR/Merge 링크 |
| 040 | Repository Docs | README, CONTRIBUTING 등 |
| 050 | Projects | Project View·작업 흐름 |
| 060 | Practice Scores | 문제은행 점수 |
| 070 | Mock Scores | 모의고사 결과 |
| 080 | Exam | 응시일·결과 |
| 090 | Reflection | 최종 회고·다음 과정 연결 |

## Lab Evidence Template

```text
Date:
Lab:
Environment:
Goal:
Commands / Actions performed:
Result:
Verification:
Related GitHub URL:
What I learned:
What I confused:
Next review date:
```

## GitHub Flow Evidence

가능하면 다음 링크를 함께 남깁니다.

```text
Repository:
Issue:
Branch:
Pull Request:
Review:
Merge commit:
Project item:
```

## Exam Evidence

시험 관련 민감 정보나 실제 시험 문제는 기록하지 않습니다.

기록 가능한 범위 예시:

```text
Exam: GH-900
Exam date:
Result: PASS / FAIL
Score: (공개 가능한 경우 본인 기록)
Strong domains:
Weak domains:
Next action:
```
