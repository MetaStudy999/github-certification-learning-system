## CLEAR 기준

`PASSED`는 GH-900 시험 합격 상태입니다. `CLEAR`는 다음을 모두 만족할 때 사용합니다.

- [ ] GH-900 합격
- [ ] 핵심 Lab 완료
- [ ] Foundations 통합 Project 80점 이상
- [ ] Evidence 정리
- [ ] 문제은행 및 Mock 기록 보존
- [ ] 핵심 개념을 다른 사람에게 설명 가능
- [ ] 다음 과정(002 Actions)으로 전달할 선수지식 정리
