# 090 Cross-Cert Review Checklist — 통합 용어 복습

## 시험 전 공통 점검

- [ ] Repository / Branch / Commit / Remote / Fork / Pull Request를 구분할 수 있다.
- [ ] Organization / Enterprise / Team / Repository Scope를 구분할 수 있다.
- [ ] Role / Permission / Policy / Ruleset의 관계를 설명할 수 있다.
- [ ] Workflow / Job / Step / Action / Runner를 구분할 수 있다.
- [ ] Secret / Variable / Token / OIDC의 역할 차이를 설명할 수 있다.
- [ ] Copilot의 Prompt / Context / Instructions / Agent 개념을 구분할 수 있다.
- [ ] Secret Protection / Supply Chain Security / Code Security를 구분할 수 있다.
- [ ] CodeQL / SARIF / SBOM / Dependabot의 역할을 설명할 수 있다.
- [ ] Agent Tool / MCP / Memory / State / Evaluation을 구분할 수 있다.
- [ ] Guardrail / Human Review / Accountability의 관계를 설명할 수 있다.

## 1문장 설명 Gate

각 항목은 **30초 이내에 한 문장으로 정의하고, 한 가지 실제 사용 Scenario를 말할 수 있을 때** 완료로 표시합니다.

## 반복 학습
