# 010 Certification Term Map — 자격증별 용어 지도

## 목적

같은 GitHub 개념이 여러 시험에서 다른 깊이로 반복되는 지점을 연결합니다.

| 공통 개념 | 001 Foundations | 002 Actions | 003 Copilot | 004 Administration | 005 Security | 006 Agentic AI |
|---|---|---|---|---|---|---|
| Repository / Branch / PR | 핵심 | Workflow 대상 | Context | Governance 대상 | Security 대상 | Agent 작업 범위 |
| Permission / Role | 기본 | Token/Runner 권한 | Policy | 핵심 | Security Role | Tool Scope |
| Actions | 제품 이해 | 핵심 | 개발 검증 연계 | Enterprise 운영 | Security Gate | Agent 실행 검증 |
| Security | 기본 보호 | Secret/OIDC | Privacy/Safeguard | 정책·Compliance | 핵심 | Guardrail |
| AI | Copilot 개요 | 보조 | 핵심 | 관리 대상 | 보안 영향 | Agent 핵심 |
| Audit / Evidence | 기본 이해 | Run 기록 | AI 검증 | 핵심 | Alert/Campaign | Accountability |

## 학습 방법

새 용어를 발견하면 먼저 해당 자격증의 `020-terms/`에서 정의를 확인하고, 이 표에서 다른 시험과의 연결을 확인합니다. 동일한 단어라도 시험마다 요구하는 **Scope와 판단 수준**이 다르다는 점을 기록합니다.
