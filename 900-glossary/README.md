# 900 Glossary — 통합 용어 Control Tower

GitHub 자격증 6종의 용어를 **중복 복제하지 않고 연결·비교·복습**하기 위한 통합 인덱스입니다.

## Quick Start

1. [`010-certification-term-map.md`](./010-certification-term-map.md)에서 자격증별 용어 영역을 확인합니다.
2. [`020-acronym-index.md`](./020-acronym-index.md)에서 시험에 반복 등장하는 약어를 한 번에 복습합니다.
3. 각 자격증의 `020-terms/`에서 상세 정의와 해당 과정의 문맥을 학습합니다.
4. [`090-review-checklist.md`](./090-review-checklist.md)로 시험 직전 교차 개념을 점검합니다.

## 표기 규칙

```text
English Full Name (Acronym) — 한국어 뜻
```

예:

- Continuous Integration (CI) — 지속적 통합
- Continuous Delivery/Deployment (CD) — 지속적 제공/배포
- Software Development Life Cycle (SDLC) — 소프트웨어 개발 생명주기
- Model Context Protocol (MCP) — 모델 컨텍스트 프로토콜
