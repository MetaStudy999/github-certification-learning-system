# 020 Acronym Index — 통합 약어 색인

시험 문제와 공식 문서에서 반복적으로 등장하는 약어를 빠르게 확인하기 위한 색인입니다.

| 약어 | English Full Name | 한국어 뜻 | 주 연결 과정 |
|---|---|---|---|
| API | Application Programming Interface | 응용 프로그램 인터페이스 | 001–006 |
| CI | Continuous Integration | 지속적 통합 | 002, 005, 006 |
| CD | Continuous Delivery/Deployment | 지속적 제공/배포 | 002, 005 |
| CLI | Command-Line Interface | 명령줄 인터페이스 | 001, 003 |
| CVE | Common Vulnerabilities and Exposures | 공통 취약점 및 노출 | 005 |
| CWE | Common Weakness Enumeration | 공통 약점 열거 | 005 |
| EMU | Enterprise Managed Users | 엔터프라이즈 관리형 사용자 | 004 |
| GHEC | GitHub Enterprise Cloud | GitHub 엔터프라이즈 클라우드 | 004 |
| GHES | GitHub Enterprise Server | GitHub 엔터프라이즈 서버 | 004 |
| HITL | Human in the Loop | 실행 과정에 사람이 참여 | 006 |
| HOTL | Human on the Loop | 사람이 감독하며 개입 가능 | 006 |
| IdP | Identity Provider | ID 공급자 | 004 |
| LLM | Large Language Model | 대규모 언어 모델 | 003, 006 |
| MCP | Model Context Protocol | 모델 컨텍스트 프로토콜 | 003, 006 |
| OIDC | OpenID Connect | OpenID 연결 | 002, 004 |
| PAT | Personal Access Token | 개인용 액세스 토큰 | 001, 004 |
| PR | Pull Request | 풀 리퀘스트 | 001–006 |
| RBAC | Role-Based Access Control | 역할 기반 접근 제어 | 004, 005 |
| SAML | Security Assertion Markup Language | 보안 어설션 마크업 언어 | 004 |

| SBOM | Software Bill of Materials | 소프트웨어 자재 명세서 | 005 |

| SSO | Single Sign-On | 통합 인증 | 004 |
| 2FA | Two-Factor Authentication | 이중 인증 | 001, 004 |

## 복습 원칙

약어만 외우지 말고 `Full Name → 한국어 의미 → 언제 쓰는가 → 어떤 시험과 연결되는가` 순으로 설명할 수 있어야 합니다.
