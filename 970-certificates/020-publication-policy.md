# 020 Publication Policy — 자격 정보 공개 기준

## 공개 가능

- 자격증명
- 시험 코드
- 취득일
- 공개용 Credential URL
- 공식적으로 공개된 유효기간/갱신 정보
- 학습 회고와 포트폴리오 링크

## 공개하지 않음

- Candidate ID
- 시험 예약 번호
- 결제 정보
- 신분증 정보
- 전화번호 / 주소
- 비공개 이메일
- 시험 화면 캡처에 포함된 민감정보
- 실제 시험 문제 또는 기억에 의존한 복원문제

## Upload Checklist

- [ ] 이미지에 개인정보가 없는가?
- [ ] QR/Barcode에 비공개 정보가 포함되지 않았는가?
- [ ] 공개용 Credential URL인가?
- [ ] 실제 시험문항이 노출되지 않는가?
- [ ] 필요한 경우 일부 정보를 마스킹했는가?

## 원칙

자격증 자체보다 **검증 가능한 공개 Credential + 실제 프로젝트 Evidence**의 조합을 포트폴리오의 기본 단위로 사용합니다.
