# 970 Certificates — 자격증 취득 기록 Control Tower

실제 취득 결과와 검증 가능한 공개 정보만 기록합니다. 학습 계획과 실제 자격 취득을 분리합니다.

## 빠른 시작 (Quick Start, QS)

1. [`010-certificate-tracker.md`](./010-certificate-tracker.md)에 실제 응시·합격 결과를 기록합니다.
2. Credential 공개 전 [`020-publication-policy.md`](./020-publication-policy.md)를 확인합니다.
3. 합격 후 각 과정의 `150-evidence/`와 `980-portfolio/`를 연결합니다.

## 현재 Certification Record (Current Certification Record, CCR)

| 코드 | 자격증 | 시험 | Result | Credential |

| 004 | GitHub 관리 (GitHub Administration, GHADM / GH-100) | GH-100 | NOT RECORDED | - |
| 005 | GitHub 고급 보안 (GitHub Advanced Security, GHAS / GH-500) | GH-500 | NOT RECORDED | - |
| 006 | GitHub 에이전틱 AI 개발자 (GitHub Agentic AI Developer, GHAI / GH-600) | GH-600 | NOT RECORDED | - |

`NOT RECORDED`는 불합격을 의미하지 않고, 이 공개 Repository에 확인 가능한 시험 결과가 아직 기록되지 않았다는 뜻입니다.

## 개인정보 원칙

Candidate ID, 결제정보, 주소, 전화번호, 개인 인증정보, 시험 예약 확인번호 등 민감한 정보는 공개 Repository에 기록하지 않습니다.
