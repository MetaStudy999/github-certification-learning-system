# 020 Terms — Agentic AI 핵심 용어

| English | 약어 | 한국어 / 핵심 의미 |
|---|---|---|
| AI Agent | Agent | 목표를 바탕으로 계획·도구 사용·결과 검증을 수행하는 AI 시스템 |
| Agentic System | - | 하나 이상의 Agent가 상태·도구·정책과 함께 동작하는 시스템 |
| Planning | - | 실행 전에 작업 순서와 성공 기준을 정리하는 단계 |
| Reasoning | - | 관찰·정보를 바탕으로 다음 판단을 만드는 과정 |
| Action | - | 외부 환경에 변화를 주는 실제 실행 단계 |
| Tool | - | Agent가 제한된 기능을 호출하기 위한 인터페이스 |
| Model Context Protocol | MCP | 모델/Agent와 외부 도구·데이터를 연결하는 표준 프로토콜 |
| Environment | - | Agent가 상호작용하는 실행·개발 환경 |
| Execution Context | - | Agent가 현재 실행되는 범위와 조건 |
| Scope | - | Agent가 접근·작업할 수 있는 범위 |
| Memory | - | 과거 정보나 경험을 재사용하기 위한 기억 구조 |
| State | - | 현재 실행의 상태·진행 상황 |
| Checkpoint | - | 실행 상태를 저장한 복구 지점 |
| Idempotency | - | 같은 작업을 반복해도 부작용이 중복되지 않는 성질 |
| Evaluation | Eval | Agent 결과의 품질·안전·성공 여부 평가 |
| Error Analysis | - | 실패 원인을 유형별로 분석하는 과정 |
| Tuning | - | 평가 결과를 바탕으로 Prompt·도구·정책·흐름을 개선 |
| Multi-Agent | - | 여러 Agent가 역할을 나누어 협업하는 구조 |
| Delegation | - | 작업 일부를 다른 Agent 또는 구성요소에 위임 |
| Handoff | - | 작업 책임이나 Context를 다음 Agent로 넘김 |
| Orchestration | - | 여러 Agent의 순서·조건·상태를 조정 |
| Guardrail | - | Agent 행동을 제한·검증하는 안전 통제 |
| Accountability | - | 누가 무엇을 왜 수행했는지 추적 가능한 책임성 |
| Human-in-the-loop | HITL | 중요한 단계에서 사람이 승인·판단에 참여 |
| Human-on-the-loop | HOTL | Agent가 실행하되 사람이 감독·개입 가능 |
| Observability | - | Agent의 계획·행동·결과를 관찰·분석 가능한 상태 |
| Artifact | - | 계획서, 로그, 평가 결과 등 검토 가능한 산출물 |

## 학습 원칙
