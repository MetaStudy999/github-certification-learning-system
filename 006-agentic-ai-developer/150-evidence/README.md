## Safety Rule

- 실제 운영 권한 확대를 Evidence 과제로 사용하지 않습니다.
- 실제 Secret·Token·Password를 기록하지 않습니다.
- 공개 저장소에 비공개 조직 정보나 민감한 운영 정보를 기록하지 않습니다.
- 실제 시험문항을 기록하지 않습니다.
