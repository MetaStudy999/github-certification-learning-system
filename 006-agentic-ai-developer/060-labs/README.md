# 060 Labs — GH-600 단계별 실습

> 모든 Lab은 학습용 Sandbox 또는 문서 기반 Scenario를 사용합니다. 실제 운영 권한 확대·안전 통제 우회·무검증 자동 실행은 다루지 않습니다.

## 공통 Lab 구조

```text
Objective
→ Concepts
→ Scenario
→ Design / Practice
→ Challenge
→ Verify
→ Evidence
```

## 완료 기준

- 기능 이름이 아니라 **설계 판단 이유**를 설명합니다.
- 자율성·도구·상태·평가·Guardrail을 함께 고려합니다.
- 모든 Lab에 성공 기준과 실패/중단 조건을 기록합니다.
