# Lab 090 — Multi-Agent Coordination

## Objective

여러 Agent가 필요한 조건과 역할 분리·Delegation·Handoff를 설계합니다.

## Scenario

다음 역할을 문서로 비교합니다.

- Planner
- Implementer
- Reviewer
- Evaluator

## Practice

```text
Shared goal:
Agent A responsibility:

Shared context:
Handoff artifact:
Conflict rule:

```

## 핵심 질문

1. 하나의 Agent로 충분한데 Multi-Agent를 쓰면 어떤 복잡성이 늘어나는가?
2. Context 공유는 어디까지 필요한가?
3. Handoff 시 어떤 Artifact가 필요한가?
4. Agent 간 판단이 충돌하면 누가 최종 결정을 하는가?
