1. Agent Architecture와 Agent Loop를 이해합니다.
2. Tool Use와 MCP(Model Context Protocol)를 학습합니다.
3. Memory와 State를 구분하고 실행 흐름에 적용합니다.
4. Evaluation과 Error Analysis를 학습합니다.
5. Multi-Agent, Guardrails, Human-in-the-loop까지 확장합니다.
