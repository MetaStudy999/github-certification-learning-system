## Q011–Q020

**Q011.** Agent가 계획을 만든 뒤 가장 적절한 다음 단계는? A 즉시 실행 B 계획 검증·승인 C 모든 Tool 허용 D 로그 삭제

**Q017.** Plan Artifact가 도움이 되는 것은? A 검토·재현·감사 B 권한 우회 C 로그 제거 D 비밀 저장  
**Q018.** Planning 단계에서 Tool 호출을 최소화하는 이유는? A 계획과 실제 행동 경계를 유지 B 속도를 항상 늦추기 위해 C Memory 제거 D UI 단순화
