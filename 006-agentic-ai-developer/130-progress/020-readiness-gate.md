# GH-600 시험 Readiness Gate (GH-600 Exam Readiness Gate, GH-600ERG)

## Mandatory

- [ ] 최신 GH-600 Study Guide 확인
- [ ] 6개 Domain과 비중 설명 가능
- [ ] 핵심 용어 90%+ 설명 가능
- [ ] Labs 80%+ 완료
- [ ] Exercises 80%+ 수행
- [ ] QBank 1회차 80%+
- [ ] QBank 2회차 85%+
- [ ] 최근 Mock 2회 연속 85%+
- [ ] 최근 오답 재시험 90%+

## Strongly Recommended

- [ ] Final Mock 90%+
- [ ] Agentic SDLC Design Project 80점+
- [ ] Confusion Matrix를 자료 없이 설명

## 의사결정 (Decision, D)

```text
Mandatory 충족
→ EXAM-READY 후보

Mandatory 미충족
→ 약점 Domain → Lab → QBank → Retry
```

`CONTENT-READY`는 학습 자료 준비 상태이고 `EXAM-READY`는 실제 학습 성과 상태입니다.
