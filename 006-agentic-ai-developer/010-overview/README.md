# 010 개요 (Overview, OVW) — GH-600

## 시험 영역 (Exam Domains, ED)

| # | 영역 (Domain, DOM) | 비중 |
|---:|---|---:|
| 1 | 에이전트 아키텍처 및 SDLC 프로세스 준비 (Prepare agent architecture and SDLC processes, AASP) | 15–20% |
| 2 | 도구 사용 및 환경 상호작용 구현 (Implement Tool Use and Environment Interaction, TUEI) | 20–25% |
| 3 | 메모리·상태·실행 관리 (Manage Memory, State, and Execution, MSE) | 10–15% |
| 4 | 평가·오류 분석·튜닝 수행 (Perform Evaluation, Error Analysis, and Tuning, EEAT) | 15–20% |
| 5 | 멀티에이전트 조정 오케스트레이션 (Orchestrate Multi-Agent Coordination, MAC) | 15–20% |
| 6 | 가드레일 및 책임성 구현 (Implement Guardrails and Accountability, GA) | 10–15% |

## 핵심 관점

GH-600은 단순 프롬프트 (Prompt, PRM) 작성 시험이 아니라 **에이전트 (Agent, AGT)가 소프트웨어 개발 수명주기 (Software Development Life Cycle, SDLC)에서 어떻게 안전하고 검증 가능하게 작동하도록 설계·감독하는가**를 평가합니다.

## 7일 단기 집중 과정 (7-Day Fast Track, 7DFT)

| 일차 (Day, D) | 학습 목표 |
|---:|---|
| 1 | 에이전트 아키텍처 / SDLC / 계획 (Agent Architecture / SDLC / Planning, AASP) |
| 2 | 도구 / MCP / 환경 상호작용 (Tools / MCP / Environment Interaction, TMEI) |
| 3 | 메모리 / 상태 / 실행 (Memory / State / Execution, MSE) |
| 4 | 평가 / 오류 분석 / 튜닝 (Evaluation / Error Analysis / Tuning, EEAT) |
| 5 | 멀티에이전트 조정 (Multi-Agent Coordination, MAC) |
| 6 | 가드레일 / 책임성 + 문제은행 (Guardrails / Accountability + QBank, GAQB) |
| 7 | 모의고사 / 최종 복습 / 시험 통과 기준 (Mock / Final Review / Exam Gate, MFEG) |

## 안전 원칙

학습은 샌드박스 (Sandbox, SBX)와 문서 기반 시나리오 (Scenario, SCN)를 사용하고 실제 운영 권한 확대·안전 통제 우회는 다루지 않습니다.
