# GH-600 Confusion 매트릭스 (GH-600 Confusion Matrix, GH-600CM)

| A | B | 핵심 차이 |
|---|---|---|
| Planning | Execution | 실행 전 계획 vs 실제 행동 |
| Reasoning | Action | 판단 과정 vs 외부 상태 변화 |
| Tool | MCP | 기능 인터페이스 vs 도구·Context 연결 표준 |
| Scope | Permission | 어디까지 vs 무엇을 할 수 있는가 |
| Memory | State | 재사용 정보 vs 현재 실행 상태 |
| Checkpoint | Memory | 복구용 상태 스냅샷 vs 재사용 정보 |
| Retry | Resume | 다시 시도 vs 저장 상태에서 이어가기 |
| Evaluation | Monitoring | 결과 품질 판단 vs 실행 관찰 |
| Error Analysis | Tuning | 실패 원인 분석 vs 개선 적용 |
| Single Agent | Multi-Agent | 단일 책임 vs 역할 분산·조정 |
| Delegation | Handoff | 작업 일부 위임 vs 책임/Context 전달 |
| Guardrail | Human Review | 자동·정책 기반 제한 vs 사람 판단 |
| HITL | HOTL | 실행 중 승인 참여 vs 감독·필요 시 개입 |
| Autonomy | Accountability | 독립 행동 범위 vs 책임 추적 가능성 |

시험 전 각 비교에 **Scenario 하나씩** 만들어 설명합니다.
