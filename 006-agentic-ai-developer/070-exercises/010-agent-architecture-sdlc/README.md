# 010 Agent Architecture / SDLC — 연습문제 (Exercises, EXR)

다음 10개 과제를 `Requirement → Design choice → Why → Evaluation → Human Review` 구조로 답합니다.

1. Agent의 Goal, Input, Output, Success Criteria가 필요한 이유를 설명하세요.
2. 단순 Chat Assistant와 SDLC Agent의 차이를 설명하세요.
3. Planning과 Execution을 분리해야 하는 이유를 3가지 제시하세요.
4. Structured Plan Artifact에 포함할 항목을 설계하세요.
5. 계획 검토 전에 실행을 허용하지 않아야 하는 Scenario를 설명하세요.
6. Agent Anti-pattern 3가지를 정의하고 완화 방법을 설명하세요.
7. Agent 자율성 수준을 Risk와 Reversibility 기준으로 판단하세요.
8. Inspectable Artifact가 Observability에 중요한 이유를 설명하세요.
9. Human Intervention이 Delivery 속도를 지나치게 늦추지 않도록 배치할 원칙을 설명하세요.
10. SDLC에서 Agent가 참여할 단계와 사람이 유지해야 할 책임을 구분하세요.

## 완료 기준

- [ ] 설계 선택 이유 설명
- [ ] 성공/실패 기준 포함
- [ ] Human Review 또는 Policy Gate 포함
