# 060 Guardrails / Accountability — 연습문제 (Exercises, EXR)

1. Agent Guardrail을 Input, Planning, Tool, Execution, Evaluation 단계로 나누어 설계하세요.
2. 최소 권한이 Agentic System에서 중요한 이유를 설명하세요.
3. Human-in-the-loop와 Human-on-the-loop의 차이를 설명하세요.
4. 위험이 높고 되돌리기 어려운 작업에 필요한 Human Review 수준을 판단하세요.
5. Agent가 어떤 판단과 행동을 했는지 추적 가능한 Artifact 목록을 설계하세요.
6. Policy 위반 가능성이 탐지되었을 때 Stop과 Escalation의 관계를 설명하세요.
7. Guardrail이 너무 강할 때 발생할 수 있는 Delivery 문제와 균형 원칙을 설명하세요.
8. 감사 가능한 Agent System에 필요한 최소 기록 항목을 정리하세요.
9. Human Reviewer에게 너무 많은 Alert를 보내는 문제를 줄이는 설계 원칙을 설명하세요.
10. Agent의 책임(Accountability)과 최종 인간 책임(Human Accountability)의 관계를 설명하세요.
