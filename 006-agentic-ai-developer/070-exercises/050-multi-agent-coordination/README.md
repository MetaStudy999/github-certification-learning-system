# 050 Multi-Agent Coordination — Exercises

1. Single Agent로 충분한 작업과 Multi-Agent가 유리한 작업을 비교하세요.
2. Planner와 Reviewer 역할을 분리하는 장단점을 설명하세요.
3. Delegation과 Handoff의 차이를 설명하세요.
4. Shared Context를 최소화해야 하는 이유와 필요한 정보 범위를 설명하세요.
5. Agent 간 결과가 충돌할 때 Resolution Rule을 설계하세요.
6. 한 Agent 실패가 전체 Workflow를 불필요하게 망가뜨리지 않도록 Failure Boundary를 정의하세요.
7. Multi-Agent에서 중복 작업을 줄이는 방법을 설명하세요.
8. Agent 간 Handoff Artifact에 포함할 항목을 정리하세요.
9. 중앙 Orchestrator와 분산 조정 방식의 개념적 차이를 설명하세요.
10. Multi-Agent 복잡성이 얻는 이점보다 큰 경우를 판단하는 기준을 작성하세요.
