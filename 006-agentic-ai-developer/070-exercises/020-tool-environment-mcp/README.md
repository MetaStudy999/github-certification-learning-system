# 020 Tool Use / Environment / MCP — Exercises

1. Agent 목표에 필요한 Tool과 불필요한 Tool을 구분하는 기준을 설명하세요.
2. Read-only Scope로 충분한 Scenario와 더 높은 권한이 필요한 Scenario를 비교하세요.
3. Least Privilege를 Agent Tool 설계에 적용하는 방법을 설명하세요.
4. MCP와 일반 Tool Interface의 관계를 설명하세요.
5. MCP Server, Registry, Allow List의 역할을 구분하세요.
6. 신뢰되지 않은 외부 Tool을 기본 허용하면 안 되는 이유를 설명하세요.
7. Repository Scope와 Branch Scope를 비교하세요.
8. CI Context에서 Agent 결과를 검증할 때 필요한 Artifact를 설계하세요.
9. Environment-specific Constraint가 있을 때 Agent의 안전한 실패 동작을 설명하세요.
10. Tool 결과가 예상과 다를 때 Agent가 계속 실행할지 중단할지 판단 기준을 작성하세요.
