# 030 Memory / State / Execution — Exercises

1. Memory와 State의 차이를 예시와 함께 설명하세요.
2. Checkpoint가 필요한 장시간 Agent 작업 Scenario를 설계하세요.
3. Retry와 Resume의 차이를 설명하세요.
4. 동일 작업 재시도에서 중복 부작용을 줄이는 Idempotency 개념을 설명하세요.
5. State에 저장해야 할 정보와 저장하지 않아야 할 정보를 구분하세요.
6. 실행 중 Context가 변경되었을 때 기존 Plan을 계속 사용할지 재검토할지 판단 기준을 작성하세요.
7. 부분 성공 후 실패한 작업의 안전한 복구 절차를 고수준으로 설계하세요.
8. State가 손상되었거나 불일치할 때 Agent가 취해야 할 안전한 동작을 설명하세요.
9. 장기 Memory가 잘못된 정보를 유지할 위험과 완화 방법을 설명하세요.
10. 실행 기록과 Artifact가 Accountability에 어떻게 연결되는지 설명하세요.
