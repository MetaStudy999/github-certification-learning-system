# 090 Final Review — GH-300 시험 직전 복습

## 핵심 비교

| A | B | 핵심 차이 |
|---|---|---|
| Completion | Chat | 코드 작성 중 제안 vs 대화형 지원 |
| Prompt | Context | 직접 지시 vs 참고 정보 |
| Zero-shot | Few-shot | 예시 없음 vs 예시 포함 |
| Generate | Refactor | 새 코드 생성 vs 기존 구조 개선 |
| Explanation | Verification | 설명 vs 실제 검증 |
| Privacy | Security | 데이터 보호 vs 시스템/코드 위험 방어 |
| Content Exclusion | Delete | Context 제외 vs 원본 삭제 |
| Suggestion | Correct Answer | AI 제안 vs 검증된 결과 |

## 시험 직전 Gate

- [ ] 7개 Domain과 비중 확인
- [ ] 주요 Copilot 기능·Plan 차이 확인
- [ ] Prompt 기본 구조 설명
- [ ] Context가 응답에 미치는 영향 설명
- [ ] Responsible AI와 Human Review 설명
- [ ] Test 생성 후 검증 필요성 설명
- [ ] Privacy / Data Handling / Content Exclusion 설명
- [ ] 최근 Mock 2회 85% 이상
- [ ] 오답 재시험 90% 이상
