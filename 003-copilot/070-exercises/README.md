## Starter Exercises

1. Completion과 Chat 중 어떤 기능이 더 적합한지 상황별로 판단합니다.
2. 모호한 Prompt를 Goal/Context/Constraints/Output/Verification 구조로 개선합니다.
3. 생성 코드에서 잘못된 가정 3개를 찾습니다.
4. Copilot이 만든 Test가 놓친 Edge Case를 추가합니다.
5. AI 생성 코드를 Production에 적용하기 전 Review Checklist를 작성합니다.
6. Prompt에 포함하면 안 되는 민감정보의 예시를 정리합니다.

## 완료 기준

답에는 **선택 기능 + 이유 + 위험 + 검증 방법**을 포함합니다.
