# 040 Official Docs — 공식 기준 자료

## 빠른 시작 (Quick Start, QS)

Copilot 제품 기능은 빠르게 바뀌므로 **시험 범위 문서와 제품 문서를 분리해서** 봅니다.

```text
1. Microsoft Learn Study Guide
   → 현재 시험 Skills Measured 확인

2. Microsoft Learn Certification Page
   → 시험 시간·언어·예약 정보 확인

3. GitHub Docs
   → 제품 기능의 현재 동작 확인

4. GitHub Learn
   → 학습경로·Practice Exam 보조 활용
```

## 주요 출처 (Primary Sources, PS)

### 010 — 시험 범위 1차 기준

**Microsoft Learn — Study guide for Exam GH-300**  
https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-300

현재 Repository 기준:

```text
Skills measured as of: 2026-08-07
```

현재 6개 Skill Area:

1. Use GitHub Copilot responsibly — 15–20%
2. Use GitHub Copilot features — 25–30%
3. Understand GitHub Copilot data and architecture — 10–15%
4. Apply prompt engineering and context crafting — 10–15%
5. Improve developer productivity with GitHub Copilot — 10–15%
6. Configure privacy, content exclusions, and safeguards — 10–15%

### 030 — GitHub 학습 (030 — GitHub Learn, GL)

https://learn.github.com/certification/COPILOT

## 변경 감시 (Change Watch, CW)

시험 전 다음을 확인합니다.

| 시점 | 확인할 것 |
|---|---|
| 학습 시작 | Skills Measured 적용일 |
| 시험 예약 전 | Certification page / 언어 / 시간 / 가격 |
| 시험 7일 전 | Study Guide Change Log |
| 시험 전날 | 제품 기능 이름·정책·Preview/GA 변화 |

## 시험 당일 규칙 (Exam-Day Rule, EDR)

Copilot 기능·Plan·CLI·Agent 기능·데이터 처리 정책은 변경될 수 있으므로 **기억한 오래된 기능표보다 최신 공식 문서를 우선**합니다.
