# 실습 (Lab, LAB) 010 — 첫 Copilot 상호작용 (First Copilot Interaction, FCI)

## 목표 (Objective, OBJ)
Copilot Completion과 Chat의 역할 차이를 직접 확인합니다.

## 실습 (Practice, PRAC)
1. 간단한 Python 함수를 작성하다가 Completion 제안을 관찰합니다.
2. 같은 함수에 대해 Chat으로 “이 함수가 무엇을 하는지 설명해 줘”라고 요청합니다.
3. Completion 결과와 Chat 응답의 목적 차이를 기록합니다.

## 도전 과제 (Challenge, CHL)
같은 문제를 Completion과 Chat으로 각각 해결하고 어느 방식이 더 적합했는지 설명합니다.

## 검증 (Verify, VER)
- [ ] Completion과 Chat을 구분한다.
- [ ] AI 제안을 그대로 적용하지 않고 Review한다.
- [ ] 실제 실행 결과를 확인한다.
