# Lab 080 — Refactoring with Copilot

## Objective
동작을 유지하면서 코드 구조를 개선하는 Refactoring을 수행합니다.

## Practice
1. 중복이 있는 작은 함수를 준비합니다.
2. Copilot에 Refactoring 목표와 유지해야 할 API를 명시합니다.
3. 제안 전후의 복잡도와 가독성을 비교합니다.
4. 기존 Test를 모두 실행합니다.

## Challenge
Copilot 제안 중 기능 변경을 유발할 수 있는 부분을 찾아 제외합니다.

## Verify
- [ ] 외부 동작이 유지된다.
- [ ] 기존 Test가 모두 통과한다.
- [ ] 변경 이유를 설명할 수 있다.
