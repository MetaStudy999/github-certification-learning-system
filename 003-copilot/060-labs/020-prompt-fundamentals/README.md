# Lab 020 — Prompt Fundamentals

## Objective
Goal, Context, Constraints, Output, Verification을 포함한 Prompt를 작성합니다.

## Practice
같은 기능 요청을 다음 두 방식으로 비교합니다.

- 짧은 Prompt: `정렬 함수 만들어 줘.`
- 구조화 Prompt: 목적·입력·제약·출력형식·Test 조건 포함

## Challenge
응답 품질 차이를 정확성, 수정 횟수, Test 가능성 기준으로 비교합니다.

## Verify
- [ ] Prompt 목적이 명확하다.
- [ ] 불필요한 Context를 줄인다.
- [ ] 성공 기준을 Prompt에 포함한다.
