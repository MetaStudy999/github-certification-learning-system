# Lab 100 — End-to-End AI-Assisted Development

## Objective
요구사항부터 검증까지 Copilot을 보조 도구로 사용하되 의사결정과 검증은 사람이 수행합니다.

## Flow

```text
Requirement
→ Prompt Plan
→ Code Generation
→ Explanation
→ Unit Tests
→ Debugging
→ Refactoring
→ Documentation
→ Human Review
→ Final Verification
```

## Practice
작은 CLI 또는 Utility 애플리케이션 하나를 선택해 전체 흐름을 수행합니다.

## Required Evidence

- Initial requirement
- 주요 Prompt 3개 이상
- 생성 코드 Review 기록
- Test 결과
- Debugging 사례 1개
- Refactoring 전후 비교
- 최종 README
- Privacy/Security Review

## Verify
- [ ] AI 없이도 최종 코드의 동작을 설명할 수 있다.
- [ ] 모든 핵심 Test가 통과한다.
- [ ] Copilot 제안을 수정하거나 거절한 사례가 있다.
- [ ] 민감정보가 Prompt/Repository에 노출되지 않았다.
