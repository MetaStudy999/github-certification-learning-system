# 060 Labs — GitHub Copilot 단계별 실습

## Lab Roadmap

| Level | Lab | 핵심 기술 |
|---:|---|---|
| 010 | First Copilot Interaction | Completion / Chat |
| 020 | Prompt Fundamentals | Goal / Context / Constraints |
| 030 | Context Engineering | File / Selection / Repository Context |
| 040 | Code Generation | 기능 구현 |
| 050 | Explanation & Documentation | 설명 / README / Comment |
| 060 | Testing | Unit Test / Edge Case |
| 070 | Debugging | Error Analysis / Fix |
| 080 | Refactoring | 구조 개선 / Review |
| 090 | Responsible AI & Privacy | 검증 / 민감정보 / Exclusion |
| 100 | End-to-End AI Development | 요구사항 → 구현 → Test → Review |

## 공통 Lab 구조

```text
Objective
→ Concept
→ Practice
→ Challenge
→ Verify
→ Evidence
```

## 안전 원칙

- 실제 Secret, Password, Token을 Prompt에 넣지 않습니다.
- AI 출력은 실행·Test·Review 전에 신뢰하지 않습니다.
- Production Code를 무검증으로 적용하지 않습니다.
- 라이선스·보안·개인정보 요구사항을 별도로 확인합니다.
