# Lab 090 — Responsible AI & Privacy

## Objective
Copilot 사용에서 Human Review, 민감정보 보호, Context Exclusion의 목적을 이해합니다.

## Practice
1. 민감정보가 포함된 예시 Prompt를 만들지 말고, 어떤 정보가 Prompt에 들어가면 안 되는지 목록화합니다.
2. AI 생성 코드에서 보안·정확성·편향·라이선스 검토 항목을 Checklist로 만듭니다.
3. Content Exclusion이 필요한 Repository 영역 예시를 설계합니다.

## Challenge
“Copilot이 생성했으므로 안전하다”는 주장에 왜 동의할 수 없는지 5문장 이내로 설명합니다.

## Verify
- [ ] Responsible AI의 핵심 책임이 사용자에게도 있음을 설명한다.
- [ ] Secret/Personal Data를 Prompt에 불필요하게 제공하지 않는다.
- [ ] Content Exclusion의 목적을 설명한다.
