# 실습 (Lab, LAB) 050 — 설명과 문서화 (Explanation & Documentation, ED)

## 목표 (Objective, OBJ)
Copilot을 코드 설명과 문서 초안 작성에 활용하되 정확성을 직접 검토합니다.

## 실습 (Practice, PRAC)
1. 기존 함수의 동작을 설명하도록 요청합니다.
2. README 사용 예시를 생성합니다.
3. 함수 Docstring 또는 주석을 제안받습니다.
4. 실제 코드와 문서가 일치하는지 검증합니다.

## 도전 과제 (Challenge, CHL)
Copilot 설명 중 과장·누락·잘못된 가정을 찾아 수정합니다.

## 검증 (Verify, VER)
- [ ] 설명이 실제 코드와 일치한다.
- [ ] 문서에 존재하지 않는 기능을 추가하지 않는다.
- [ ] 필요한 수준 이상의 장황한 주석을 제거한다.
