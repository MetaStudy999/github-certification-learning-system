# 실습 (Lab, LAB) 070 — Copilot 활용 디버깅 (Debugging with Copilot, DC)

## 목표 (Objective, OBJ)
오류 메시지와 재현 조건을 Context로 제공해 Debugging을 수행합니다.

## 실습 (Practice, PRAC)
1. 의도적으로 실패하는 작은 코드 또는 Test를 준비합니다.
2. 오류 메시지와 관련 코드만 Context로 제공합니다.
3. 원인 후보를 설명하도록 요청합니다.
4. 수정안을 적용하기 전에 원인을 직접 확인합니다.
5. 수정 후 Test를 다시 실행합니다.

## 도전 과제 (Challenge, CHL)
Copilot의 첫 번째 원인 추정이 틀렸을 때 어떤 추가 Context가 필요했는지 기록합니다.

## 검증 (Verify, VER)
- [ ] 오류를 재현할 수 있다.
- [ ] 원인과 증상을 구분한다.
- [ ] 수정 후 Test로 검증한다.
