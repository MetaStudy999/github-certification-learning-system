# 실습 (Lab, LAB) 030 — 컨텍스트 엔지니어링 (Context Engineering, CE)

## 목표 (Objective, OBJ)
Copilot에 제공되는 Context가 응답 품질에 미치는 영향을 이해합니다.

## 실습 (Practice, PRAC)
1. 관련 파일을 열지 않은 상태에서 코드 수정 요청을 합니다.
2. 관련 함수·Test·오류 메시지를 Context로 제공한 뒤 같은 요청을 반복합니다.
3. 정확도와 수정 범위를 비교합니다.

## 도전 과제 (Challenge, CHL)
필요한 Context와 불필요한 Context를 분류합니다.

## 검증 (Verify, VER)
- [ ] Prompt와 Context의 차이를 설명한다.
- [ ] 민감정보를 Context에서 제거한다.
- [ ] 관련성 높은 Context만 제공한다.
