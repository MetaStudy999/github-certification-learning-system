# 실습 (Lab, LAB) 060 — Copilot 활용 테스트 (Testing with Copilot, TC)

## 목표 (Objective, OBJ)
Copilot으로 Test 초안을 만들고 Edge Case를 보강합니다.

## 실습 (Practice, PRAC)
1. 대상 함수의 정상 입력 Test를 생성합니다.
2. Empty, Boundary, Invalid Input을 추가 요청합니다.
3. 생성된 Test가 실제 요구사항을 검증하는지 확인합니다.
4. 실패 Test가 의미 있는 실패인지 확인합니다.

## 도전 과제 (Challenge, CHL)
Copilot이 놓친 Edge Case 3개를 직접 추가합니다.

## 검증 (Verify, VER)
- [ ] 정상/경계/예외 Test가 있다.
- [ ] Test가 구현 세부사항보다 동작을 검증한다.
- [ ] 생성된 Test 자체도 사람이 Review한다.
