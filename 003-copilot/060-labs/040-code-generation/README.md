# 실습 (Lab, LAB) 040 — 코드 생성 (Code Generation, CG)

## 목표 (Objective, OBJ)
Copilot으로 작은 기능을 생성하고 Human Review로 검증합니다.

## 실습 (Practice, PRAC)
요구사항이 명확한 Python 기능 하나를 선택해 다음 순서로 진행합니다.

```text
Requirement
→ Prompt
→ Generated Code
→ Review
→ Run
→ Fix
```

## 도전 과제 (Challenge, CHL)
생성 코드에서 입력 검증, 예외 처리, Naming, 복잡도를 직접 점검합니다.

## 검증 (Verify, VER)
- [ ] 요구사항과 생성 결과를 대조한다.
- [ ] 실행 가능한지 확인한다.
- [ ] AI가 만든 불필요한 코드를 제거한다.
