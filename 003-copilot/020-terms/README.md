# 020 Terms — GitHub Copilot 핵심 용어

| English | 약어 | 한국어/핵심 의미 |
|---|---|---|
| Artificial Intelligence | AI | 인공지능 |
| Generative AI | GenAI | 생성형 인공지능 |
| Large Language Model | LLM | 대규모 언어 모델 |
| Prompt | - | AI에 주는 지시·질문 |
| Context | - | 응답 생성에 참고되는 정보 |
| Token | - | 모델이 처리하는 텍스트 단위 |
| Context Window | - | 한 번에 참고 가능한 Context 범위 |
| Code Completion | - | 코드 자동 완성 |
| Copilot Chat | - | 대화형 AI 개발 지원 |
| Inline Chat | - | 코드 위치에서 바로 수행하는 대화형 지원 |
| Prompt Engineering | - | 더 적절한 응답을 얻기 위한 Prompt 설계 |
| Zero-shot | - | 예시 없이 지시 |
| Few-shot | - | 소수 예시를 포함한 지시 |
| Hallucination | - | 사실과 다른 생성 결과 |
| Responsible AI | RAI | 책임 있는 AI 사용 원칙 |
| Privacy | - | 개인정보·데이터 보호 |
| Content Exclusion | - | 특정 콘텐츠를 Copilot Context에서 제외 |
| Refactoring | - | 동작을 유지하며 코드 구조 개선 |
| Unit Test | - | 작은 코드 단위 검증 |
| Debugging | - | 오류 원인 분석·수정 |
