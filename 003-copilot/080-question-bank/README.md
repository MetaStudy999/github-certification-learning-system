# 080 Question Bank — GH-300 자체 문제은행

> 실제 시험 문항이나 Brain Dump를 복제하지 않습니다. **Microsoft Learn GH-300 Skills Measured as of 2026-08-07**을 바탕으로 독립 제작한 학습 문제만 사용합니다.

## Quick Start

문제를 먼저 풀고 `<details>`의 정답을 확인합니다.

```text
문제
→ 내 답
→ 정답
→ 왜 정답인가
→ 왜 다른 선택지는 덜 적절한가
→ 관련 Skill Area
→ 관련 Lab
→ 재시험
```

## 문제 설계 원칙

- 기능 이름 암기보다 **상황 판단**을 우선합니다.
- `BEST`, `MOST appropriate`, `FIRST` 유형의 사고를 연습합니다.
- AI Output을 무비판적으로 신뢰하는 선택지는 경계합니다.
- 최신 기능(Agent Mode, CLI, MCP, Code Review, Spaces, Spark, Instructions)을 포함합니다.
- 제품 세부 동작이 바뀔 수 있는 내용은 공식 Docs와 재검증합니다.
- 실제 시험 문항을 기억해 재작성하지 않습니다.
