## Question Cycle

```text
문제
→ 내 답
→ 정답
→ 왜 정답인가
→ 왜 대안은 덜 적절한가
→ 관련 공식문서
→ 관련 Lab
→ 재시험
```

## Gate

- 1회차 80% 이상
- 2회차 85% 이상
- 오답 재시험 90% 이상

## 원칙

- 제품 기능 이름만 암기하지 않습니다.
- Scenario 기반 기능 선택 문제를 포함합니다.
- Responsible AI와 Privacy를 별도 고비중 약점으로 관리합니다.
- 제품 기능 변경 가능성이 있으므로 최신 공식문서와 교차 확인합니다.
