## Content Gate vs Exam Gate

```text
CONTENT-READY
= 학습 자료가 준비됨

EXAM-READY
= 사용자가 실제로 학습·실습·문제풀이 기준을 통과함
```

두 상태를 절대 같은 의미로 사용하지 않습니다.
