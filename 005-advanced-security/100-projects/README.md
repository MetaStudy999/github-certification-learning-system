## Project 001 — Secure SDLC Integration Project

### 목표

학습용 Repository에 GitHub Security 기능을 하나의 안전한 개발 흐름으로 통합합니다.

```text
Code
→ Push Protection
→ Pull Request
→ Dependency Review
→ CodeQL / Code Security
→ Merge Security Gate
→ Security Overview
→ Triage / Campaign
→ Remediation
→ Enterprise Policy
```

- [ ] SARIF 역할 설명
