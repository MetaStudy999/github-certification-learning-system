# Secure SDLC Project — Evidence Checklist

- [ ] 프로젝트 목표와 학습용 Repository 범위
- [ ] Security Suite 아키텍처 다이어그램
- [ ] Secret Protection 설계 근거
- [ ] Supply Chain Security 설계 근거
- [ ] CodeQL Setup 선택 근거
- [ ] Alert Triage 사례 1개 이상
- [ ] Security Campaign 설계 예시
- [ ] 정책 Scope / Role / Exception 기준
- [ ] 수정 전후 검증 결과
- [ ] QBank / Mock 점수 기록
- [ ] 최종 Reflection

## Evidence 안전 규칙

- 실제 Secret·Token·Password는 기록하지 않습니다.
- 조직의 비공개 보안 정책 원문을 공개 저장소에 복제하지 않습니다.
- Screenshot에는 민감정보가 없는지 확인합니다.
- 가능한 경우 URL + 설명 + 검증 결과를 함께 기록합니다.
