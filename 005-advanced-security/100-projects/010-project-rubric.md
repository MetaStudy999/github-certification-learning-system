# Secure SDLC Integration Project — Rubric

| 평가 영역 | 배점 | PASS 기준 |
|---|---:|---|
| Secure SDLC Architecture | 15 | 예방→탐지→대응 흐름 설명 |
| Secret Protection | 15 | 탐지/Push Protection/예외 Governance 설명 |
| Supply Chain Security | 15 | Graph/Alert/Review/SBOM 연결 |
| Code Security | 20 | CodeQL Setup 선택과 결과 해석 |
| Security Operations | 15 | Prioritization/Campaign/Remediation 설계 |
| Administration | 10 | Scope/Role/Policy/Exception 설명 |
| Evidence / Explainability | 10 | 재현 가능한 기록과 검증 |
| **합계** | **100** | |

## 판정

- 0–79: 보완 필요
- 80–89: `PASS`
- 90–100 + Evidence 완료: `CLEAR` 후보

## 감점 원칙

- 실제 민감정보를 학습자료에 기록
- 기능을 나열만 하고 선택 이유가 없음
- Dismiss/Exception에 근거·감사 설계가 없음
- 결과 검증 없이 완료 처리
