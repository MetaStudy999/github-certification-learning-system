# 실습 (Lab, LAB) 090 — 보안 캠페인 (Security Campaigns, SC)

## 목표 (Objective, OBJ)

다수 Repository의 Security Alert를 Campaign으로 묶어 우선순위 기반 Remediation을 관리하는 방식을 이해합니다.

## 실습 (Practice, PRAC)

1. 동일 CWE 또는 위험 유형의 Alert를 Campaign으로 묶는 Scenario를 작성합니다.
2. Campaign 목표, 대상 Repository, Owner, Deadline, Success Metric을 정의합니다.
3. Developer와 Security Team 역할을 구분합니다.
4. 진행률이 낮을 때 Escalation 절차를 작성합니다.
5. Campaign 종료 후 남은 Risk와 재발 방지 정책을 정리합니다.

## 검증 (Verify, VER)

- [ ] Security Overview와 Campaign 차이 설명 가능
- [ ] Campaign Success Metric 설계 가능
- [ ] 대규모 Remediation 흐름 설명 가능
