# 실습 (Lab, LAB) 010 — 보안 제품군 개요 (Security Suites Overview, SSO)

## 목표 (Objective, OBJ)

GitHub Security Suites의 구조와 Security Overview에서 위험을 탐색하는 흐름을 이해합니다.

## 실습 (Practice, PRAC)

1. 학습용 Repository 또는 Organization의 Security 화면을 확인합니다.
2. Secret Protection, Supply Chain Security, Code Security가 각각 어떤 위험을 표시하는지 표로 정리합니다.
3. Alert 상태, Severity, Repository, 담당자 정보를 구분합니다.
4. Security Overview가 개별 Repository Alert와 무엇이 다른지 설명합니다.

## 도전 과제 (Challenge, CHL)

`Secret / Dependency / Code` 3종 위험이 동시에 존재하는 가상 조직에서 우선순위 판단 기준을 작성하세요.

## 검증 (Verify, VER)

- [ ] 3개 Suite 역할 설명 가능
- [ ] Security Overview 목적 설명 가능
- [ ] Alert Ownership과 Prioritization 필요성 설명 가능
