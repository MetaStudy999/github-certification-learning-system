# 실습 (Lab, LAB) 070 — CodeQL 고급 설정과 SARIF (CodeQL Advanced Setup & SARIF, CASSARIF)

## 목표 (Objective, OBJ)

Advanced Setup과 SARIF 기반 외부 분석 결과 통합을 이해합니다.

## 실습 (Practice, PRAC)

1. Advanced Setup이 필요한 Scenario를 3개 작성합니다.
2. Workflow에서 언어 Matrix, Query Suite, Scan Trigger를 제어하는 이유를 설명합니다.
3. SARIF가 서로 다른 분석 도구의 결과를 GitHub Code Scanning에 전달하는 역할을 설명합니다.
4. 외부 CI에서 생성한 SARIF를 GitHub에 업로드하는 Architecture를 그립니다.
5. Custom Query 사용 시 정확도·유지보수·False Positive 관점을 정리합니다.

## 검증 (Verify, VER)

- [ ] Advanced Setup 사용 이유 설명 가능
- [ ] SARIF의 역할 설명 가능
- [ ] Native CodeQL vs Third-party Scanner 통합 차이 설명 가능
