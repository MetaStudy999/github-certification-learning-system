# 실습 (Lab, LAB) 050 — 의존성 검토와 SBOM (Dependency Review & SBOM, DRSBOM)

## 목표 (Objective, OBJ)

PR 단계에서 Dependency 변화를 검토하고 SBOM으로 구성요소 정보를 관리합니다.

## 실습 (Practice, PRAC)

1. Dependency Review가 PR에 새로 추가·변경된 Dependency를 어떻게 보여 주는지 확인합니다.
2. 취약성뿐 아니라 License/Policy 관점의 검토 항목을 정리합니다.
3. Dependency Review를 Pre-merge Gate로 사용할 때 장점과 운영 부담을 설명합니다.
4. SBOM의 목적과 Dependency Graph의 차이를 설명합니다.
5. SBOM Export가 Supply Chain 조사·감사에 어떻게 활용되는지 정리합니다.

## 검증 (Verify, VER)

- [ ] Dependency Review와 Dependabot Alert 차이 설명 가능
- [ ] SBOM 목적 설명 가능
- [ ] PR 단계 Supply Chain Gate 설계 가능
