# Lab 080 — Alert Triage & Autofix

## Objective

Security Alert를 Context 기반으로 분류하고 Remediation/Autofix 결과를 검증합니다.

## Practice

1. Severity, Exploitability, Asset 중요도, 노출 범위를 기준으로 Triage 순서를 정합니다.
2. Alert를 `Fix / Accept Risk / False Positive / Defer`로 분류하는 기준을 작성합니다.
3. Dismissal에 근거와 재검토 시점이 필요한 이유를 설명합니다.
4. Autofix 제안을 그대로 신뢰하지 않고 Review/Test해야 하는 이유를 정리합니다.
5. 수정 후 재분석 결과를 Evidence로 남기는 방식을 설계합니다.

## Verify

- [ ] Severity만으로 우선순위를 정하면 안 되는 이유 설명 가능
- [ ] Dismissal과 Remediation 차이 설명 가능
- [ ] Autofix 검증 절차 설명 가능
