# 010 Overview — GH-500

## 시험 영역 — July 2026

| Domain | 비중 |
|---|---:|
| Security suites, features, ecosystem | 15–20% |
| Secret Protection | 15–20% |
| Supply Chain Security | 15–20% |
| Code Security | 10–15% |
| Security Operations | 15–20% |
| Security Suites Administration | 10–15% |

## 학습 핵심

```text
예방
→ 탐지
→ Alert
→ 우선순위
→ 수정
→ 정책 / 자동화
→ 재발 방지
```

## 핵심 질문

- Secret Protection과 Code Security는 어떤 위험을 다루는가?
- Dependency Graph, Dependabot, Dependency Review, SBOM은 어떻게 연결되는가?
- CodeQL과 SARIF는 어떤 역할을 하는가?
- Alert를 무조건 Dismiss하면 안 되는 이유는 무엇인가?
- Security Campaign은 대규모 Remediation에 어떻게 활용되는가?
- Enterprise/Organization에서 보안 기능을 어떻게 일관되게 Rollout하는가?
