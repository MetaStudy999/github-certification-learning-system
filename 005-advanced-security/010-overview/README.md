# 010 개요 (Overview, OVW) — GH-500

## 시험 영역 (Exam Domains, ED) — 2026년 7월

| 영역 (Domain, DOM) | 비중 |
|---|---:|
| 보안 제품군·기능·생태계 (Security suites, features, ecosystem, SFE) | 15–20% |
| 비밀 보호 (Secret Protection, SP) | 15–20% |
| 공급망 보안 (Supply Chain Security, SCS) | 15–20% |
| 코드 보안 (Code Security, CS) | 10–15% |
| 보안 운영 (Security Operations, SO) | 15–20% |
| 보안 제품군 관리 (Security Suites Administration, SSA) | 10–15% |

## 학습 핵심

```text
예방
→ 탐지
→ 경고 (Alert, ALT)
→ 우선순위
→ 수정
→ 정책 / 자동화
→ 재발 방지
```

## 핵심 질문

- 비밀 보호 (Secret Protection, SP)와 코드 보안 (Code Security, CS)은 어떤 위험을 다루는가?
- 의존성 그래프 (Dependency Graph, DG), Dependabot, 의존성 검토 (Dependency Review, DR), 소프트웨어 자재 명세서 (Software Bill of Materials, SBOM)는 어떻게 연결되는가?
- CodeQL과 정적 분석 결과 교환 형식 (Static Analysis Results Interchange Format, SARIF)은 어떤 역할을 하는가?
- 경고 (Alert, ALT)를 무조건 해제 (Dismiss, DSM)하면 안 되는 이유는 무엇인가?
- 보안 캠페인 (Security Campaign, SC)은 대규모 수정 (Remediation, REM)에 어떻게 활용되는가?
- 엔터프라이즈 / 조직 (Enterprise / Organization, EO)에서 보안 기능을 어떻게 일관되게 도입 (Rollout, RO)하는가?
