# 005 GitHub Advanced Security

**Exam:** GH-500  
**Status:** PLANNED

## Quick Start

1. Secure SDLC와 GitHub 보안 기능의 관계를 이해합니다.
2. CodeQL과 Code Scanning을 학습합니다.
3. Secret Protection과 Push Protection을 학습합니다.
4. Dependabot, Dependency Graph, Dependency Review를 정리합니다.
5. Security Operations와 Administration 관점까지 확장합니다.

## 핵심 영역

- Secure SDLC
- CodeQL / Code Scanning
- Secret Protection / Push Protection
- Dependabot / Dependency Graph / Dependency Review
- Supply Chain Security
- SBOM / SARIF
- Security Alert / Security Operations
- Security Administration

## 대표 프로젝트

GitHub Actions, CodeQL, Dependabot, Secret Protection을 하나의 저장소에 통합한 Secure SDLC 실습 프로젝트를 구성합니다.
