# GH-500 실습 증빙 템플릿 (Lab Evidence Template, LET)

```text
Date:
Lab:
Domain:
Learning repository:
Risk / objective:
GitHub feature:
Configuration summary:
Expected result:
Actual result:
Verification:
Evidence URL / screenshot reference:
What changed after verification:
Security notes:
What I learned:
```

## 안전 규칙

- 실제 Secret·Token·Password를 넣지 않습니다.
- Screenshot과 URL에 민감정보가 없는지 확인합니다.
- 학습용 환경과 실제 Production 환경을 구분합니다.
