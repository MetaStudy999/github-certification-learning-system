## 안전 원칙

- 실제 Secret, Token, Password를 기록하지 않습니다.
- 공개 Repository에 조직의 실제 비공개 보안정보를 기록하지 않습니다.
- 학습용 환경과 Production 환경을 명확히 구분합니다.
- 실제 시험 문항·복원 문제를 Evidence로 남기지 않습니다.
