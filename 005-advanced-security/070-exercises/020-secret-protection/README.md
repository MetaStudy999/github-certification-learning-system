# 020 Secret Protection — Exercises

> 자격증 학습용 과제이며 실제 민감정보나 운영 자격증명을 사용하지 않습니다.

1. Secret Protection과 Push Protection의 역할 차이를 설명하세요.
2. 사전 차단과 사후 Alert 대응의 차이를 비교하세요.
3. Validity Check가 Alert 우선순위 판단에 어떤 도움을 주는지 설명하세요.
4. Custom Pattern이 필요한 조직 시나리오를 예로 드세요.
5. Repository 수준과 Organization 수준 설정의 차이를 설명하세요.
6. Public Repository와 Private/Enterprise 환경에서의 운영 차이를 정리하세요.
7. 개발자가 보안 경고를 마주했을 때 안전한 대응 흐름을 설명하세요.
8. 예외 처리가 필요한 경우 승인·근거·기록이 필요한 이유를 설명하세요.
9. 노출된 자격증명 대응에서 회수·교체·검증의 개념을 설명하세요.
10. Secret Protection을 Secure SDLC의 어느 단계에 배치할지 설명하세요.

## 완료 기준

- 실제 Secret 값은 사용하지 않습니다.
- 기능 선택 이유와 검증 방법을 함께 설명합니다.
