# 050 Security Operations / Administration — Exercises

1. Security Overview와 Security Campaign의 목적 차이를 설명하세요.
2. Alert Prioritization에서 심각도 외에 고려할 조직적 요소를 설명하세요.
3. Alert Dismissal과 Remediation의 차이를 설명하세요.
4. Security Campaign의 대상·기한·책임자를 정의하는 이유를 설명하세요.
5. Developer, Security Team, Administrator의 책임을 구분하세요.
6. Organization/Enterprise 수준 정책과 Repository 수준 설정의 관계를 설명하세요.
7. Delegated Bypass 또는 예외 권한을 최소화해야 하는 이유를 설명하세요.
8. Default Configuration을 활용한 대규모 보안 기능 Rollout의 장점을 설명하세요.
9. API/Automation을 사용할 때 변경 추적·권한·감사가 중요한 이유를 설명하세요.
10. 여러 Repository의 보안 위험을 줄이기 위한 분기별 운영 Runbook을 설계하세요.

## 완료 기준

각 답변에 Scope, Role, Policy, Evidence를 포함합니다.
