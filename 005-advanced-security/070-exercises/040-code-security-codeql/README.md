# 040 Code Security / CodeQL — Exercises

1. Code Security와 Secret Protection의 탐지 대상 차이를 설명하세요.
2. CodeQL Default Setup과 Advanced Setup을 비교하세요.
3. Default Setup이 적합한 팀과 Advanced Setup이 필요한 팀을 각각 예로 드세요.
4. SARIF가 분석 엔진이 아니라 결과 교환 형식이라는 점을 설명하세요.
5. 정적 분석 Alert의 위치·심각도·영향 범위를 함께 봐야 하는 이유를 설명하세요.
6. 여러 언어를 사용하는 Repository에서 분석 범위를 설계할 때 고려할 항목을 정리하세요.
7. False Positive 가능성이 있는 Alert를 검토할 때 필요한 근거를 설명하세요.
8. PR 기반 보안 분석과 정기 분석을 함께 사용하는 이유를 설명하세요.
9. CodeQL 결과를 개발 Workflow에 통합할 때 개발자 경험과 보안 통제를 균형 있게 고려하는 방법을 설명하세요.
10. Code Security 결과를 Security Operations의 우선순위·Remediation 흐름과 연결하세요.

## 완료 기준

- 기능 정의뿐 아니라 적용 시나리오를 설명합니다.
- 운영 환경을 약화시키는 절차 대신 설계·판단 중심으로 답합니다.
