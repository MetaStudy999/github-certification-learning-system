# 030 Supply Chain Security — Exercises

1. Dependency Graph과 SBOM의 목적 차이를 설명하세요.
2. Dependabot Alert와 Dependency Review의 차이를 비교하세요.
3. Pull Request에서 새로운 의존성 위험을 검토하는 흐름을 설명하세요.
4. 알려진 취약점이 있는 의존성을 발견했을 때 개발팀의 대응 순서를 정리하세요.
5. Direct Dependency와 Transitive Dependency를 구분하세요.
6. SBOM이 규정 준수·자산 파악·사고 대응에 유용한 이유를 설명하세요.
7. 자동 업데이트와 수동 검토를 함께 운영해야 하는 이유를 설명하세요.
8. 의존성 변경의 위험도를 판단할 때 버전·출처·영향 범위를 어떻게 고려할지 설명하세요.
9. Supply Chain Security를 CI/CD와 연결하는 고수준 운영 흐름을 설계하세요.
10. 취약점 Alert를 단순히 닫는 것과 실제 Remediation의 차이를 설명하세요.
