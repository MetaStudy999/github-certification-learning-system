# 010 Security Suites / Secure SDLC — 연습문제 (Exercises, EXR)

> 자격증 학습용 고수준 과제입니다. 실제 운영 환경을 변경하거나 보안 통제를 약화시키는 절차는 포함하지 않습니다.

1. GitHub의 코드, 자격증명, 의존성 보안 기능을 역할별로 비교하세요.
2. 예방형 통제와 사후 탐지의 차이를 설명하세요.
3. Pull Request 단계에서 의존성 위험을 검토하는 학습 흐름을 설명하세요.
4. 정적 분석 결과의 우선순위 판단 기준을 정리하세요.
5. Security Overview의 개발팀·보안팀 활용 차이를 설명하세요.
6. Prevention-first와 Merge Gate 전략의 차이를 비교하세요.
7. Security Campaign의 목적과 일반 Alert 목록의 차이를 설명하세요.
8. Alert 상태 변경 시 필요한 근거와 감사 가능성을 설명하세요.
9. Public Repository와 Enterprise 환경의 보안 기능 운영 차이를 조사하세요.
10. Secure SDLC를 Commit 이전 → PR → Merge → 사후 개선 흐름으로 설명하세요.

## 완료 기준

각 답변에 기능 이름, 선택 이유, 대안, 검증 방법을 포함합니다.
