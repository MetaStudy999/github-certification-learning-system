# GH-500 시험 Readiness Gate (GH-500 Exam Readiness Gate, GH-500ERG)

## Mandatory

- [ ] 최신 Microsoft Learn GH-500 Study Guide 확인
- [ ] 6개 Domain과 비중 설명 가능
- [ ] 핵심 용어 90% 이상 설명 가능
- [ ] 핵심 Labs 80% 이상 완료
- [ ] Exercises 80% 이상 수행
- [ ] QBank 1회차 80% 이상
- [ ] QBank 2회차 85% 이상
- [ ] 최근 Mock 2회 연속 85% 이상
- [ ] 최근 오답 재시험 90% 이상

## Strongly Recommended

- [ ] Final Mock 90% 이상
- [ ] Secure SDLC Project 80점 이상
- [ ] Confusion Matrix 12개 비교를 자료 없이 설명

## 의사결정 (Decision, D)

```text
모든 Mandatory 충족
        ↓
EXAM-READY 후보

Mandatory 미충족
        ↓
약점 Domain → Lab → QBank → Retry
```

`CONTENT-READY`는 자료 준비 상태이고, `EXAM-READY`는 실제 학습 성과 상태입니다.
