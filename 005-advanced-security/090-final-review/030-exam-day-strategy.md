# GH-500 시험-Day 전략 (GH-500 Exam-Day Strategy, GH-500ES)

## 1. 문제 읽기

`BEST`, `FIRST`, `MOST appropriate`, Scope(Repository/Organization/Enterprise), 예방/탐지/대응 시점을 먼저 표시합니다.

## 2. 선택지 제거

다음 순서로 제거합니다.

1. 요구 Risk와 무관한 기능
2. Scope가 잘못된 기능
3. 사전 예방이 필요한데 사후 대응만 제공하는 선택지
4. 최소 권한·감사·검증 원칙에 어긋나는 선택지

## 3. 시간 관리

- 1차: 확실한 문제 우선
- 2차: 비교 개념 문제
- 3차: 긴 Scenario와 검토 표시 문제
- 마지막: 미응답 여부 확인

## 4. 시험 직전 금지

- 새로운 비공식 Brain Dump 학습
- 기능 이름 대량 추가 암기
- 약점 Domain을 무시한 채 응시

공식 Study Guide와 자신의 오답노트만 압축 복습합니다.
