# 940 Labs — 통합 실습 Control Tower

6개 자격증의 실습을 **설명 → 실행 → 검증 → Evidence** 흐름으로 연결하는 공통 실습 인덱스입니다.

## 빠른 시작 (Quick Start, QS)

1. [`010-lab-index.md`](./010-lab-index.md)에서 과정별 Lab으로 이동합니다.
2. 각 Lab은 [`020-lab-standard.md`](./020-lab-standard.md)의 공통 구조를 따릅니다.
3. 실습 후 반드시 Verify를 수행합니다.
4. 결과는 각 과정의 `150-evidence/`에 기록합니다.
5. [`090-verification-standard.md`](./090-verification-standard.md)에서 PASS 기준을 확인합니다.

## Standard Lab 흐름 (Standard Lab Flow, SLF)

```text
Objective
→ Prerequisites
→ Concepts
→ Practice / Scenario
→ Challenge
→ Verify
→ Evidence
→ Reflection
```

## 안전 원칙

- 운영 환경의 권한·보안 통제를 학습 목적으로 약화시키지 않습니다.
- Secret, Token, Password를 공개 저장소에 기록하지 않습니다.
- 취약 코드나 보안 Scenario는 격리된 학습용 환경에서 사용합니다.
- Agentic AI 실습은 최소 권한, 검토 가능한 산출물, Human Review를 기본으로 합니다.
