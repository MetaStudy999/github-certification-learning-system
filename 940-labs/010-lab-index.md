## Lab 사용 순서

각 과정의 Lab 번호를 앞에서부터 수행하되, 문제은행·Mock에서 특정 Error Code가 반복되면 해당 개념의 Lab으로 다시 돌아갑니다.

```text
Learn Lab
→ Verify
→ Question Bank
→ Error detected
→ Weak Lab 다시 수행
→ Retry
```
