# 020 Lab Standard — 공통 실습 작성 표준

## 권장 구조 (Recommended Structure, RS)

```text
# Lab Title

## 001. Objective — 목표
## 002. Why — 왜 필요한가
## 003. Prerequisites — 사전지식/환경
## 004. Concepts — 핵심 개념
## 005. Practice — 따라하기
## 006. Challenge — 스스로 해보기
## 007. Verify — 검증
## 008. Troubleshooting — 문제 해결
## 009. Evidence — 증거 기록
## 010. Reflection — 회고
```

## 검증 Standard (Verify Standard, VS)

Verify는 단순히 `명령이 실행됐다`가 아니라 다음 세 가지를 확인합니다.

1. **Expected State** — 기대 상태가 무엇인지 정의
2. **Observation** — 실제 결과를 확인
3. **Decision** — PASS/FAIL 및 다음 행동 결정

## 최소 증빙 기준 (Evidence Minimum, EM)

```text
Date:
Certification / Lab:
Environment:
Goal:
Commands / Configuration:
Expected Result:
Actual Result:
Verification:
Evidence Link:
Troubleshooting:
What I learned:
```

## Beginner 규칙 (Beginner Rule, BR)

입문자 문서는 명령어만 나열하지 않고 `왜 하는가 → 무엇을 하는가 → 실행 → 결과 확인 → 실패 시 복구` 순으로 설명합니다.
