# 010 Error Code Map — 통합 오류 원인 지도

| 오류 코드 | 질문 | 기본 조치 |
|---|---|---|
| CONCEPT | 개념 자체를 이해하지 못했는가? | Terms → Concepts 재학습 |
| COMPARE | 비슷한 기능을 혼동했는가? | Confusion Matrix 작성 |
| MEMORY | 알고 있었지만 기억하지 못했는가? | 1문장 정의 + 간격 반복 |
| READING | 조건·부정어·범위를 놓쳤는가? | 문제 문장 구조 재분석 |
| SCOPE | Enterprise/Org/Repo/User 범위를 틀렸는가? | Scope 표 다시 작성 |
| PRACTICE | 실제 사용 경험이 부족한가? | 관련 Lab 재수행 |
| SECURITY | 최소 권한·보안 통제를 잘못 판단했는가? | 안전한 기본값과 정책 재확인 |
| TROUBLE | 진단·수정 순서를 잘못 선택했는가? | 관찰 → 원인 → 최소 변경 → Verify 순서 연습 |
| SCENARIO | 기능은 알지만 상황 적용이 틀렸는가? | 요구사항 → 제약 → 최선 대안 비교 |
| REPEAT | 같은 개념을 다시 틀렸는가? | 문제풀이 중단 후 근본 개념 재학습 |

## 과정별 전문 코드 예시

- Actions: Runner, Permission, Expression, Reuse
- Copilot: Prompt, Context, Privacy, Responsible AI
- Administration: Identity, Policy, Scope, Audit
- Advanced Security: Secret, Supply Chain, CodeQL, Triage, Campaign
- Agentic AI: Architecture, Tool, MCP, State, Evaluation, Multi-Agent, Guardrail

전문 코드는 각 과정 `120-wrong-answers/`의 정의를 우선합니다.
