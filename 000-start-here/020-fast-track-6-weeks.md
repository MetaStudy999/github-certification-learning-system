# 020 Fast Track — 6주 단기 취득 계획

## 목표

6주 동안 GitHub 자격증 6종을 순차적으로 준비하되, 시험일을 절대 고정하지 않고 준비도 Gate를 통과했을 때 응시합니다.

| 주차 | 목표 |
|---:|---|
| Week 1 | GitHub Foundations |
| Week 2 | GitHub Copilot |
| Week 3 | GitHub Actions |
| Week 4 | GitHub Administration |
| Week 5 | GitHub Advanced Security |
| Week 6 | GitHub Agentic AI Developer |

## 하루 학습 Cycle

```text
공식 학습
  ↓
핵심 개념 정리
  ↓
직접 실습
  ↓
문제풀이
  ↓
오답 분석
  ↓
다음 날 재시험
```

## Exam Readiness Gate

- 공식 학습 자료 100%
- 필수 용어 90% 이상
- 실습 80% 이상
- 문제은행 80% 이상
- 모의고사 2회 연속 85% 이상
- 최근 오답 재시험 90% 이상

Gate를 통과하지 못하면 시험을 강행하지 않고 1~3일 보강합니다.
