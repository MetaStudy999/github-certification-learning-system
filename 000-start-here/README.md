# 000 Start Here — 시작 안내

## Quick Start

1. `010-learning-roadmap.md`에서 장기 학습 순서를 확인합니다.
2. `020-fast-track-6-weeks.md`에서 6주 단기 취득 계획을 확인합니다.
3. 첫 과정은 `../001-foundations/README.md`에서 시작합니다.
4. 각 자격증의 시험 준비도 Gate를 통과한 뒤 응시합니다.

## 전체 학습 원칙

- 장기 역량 순서: Foundations → Actions → Copilot → Administration → Advanced Security → Agentic AI Developer
- 단기 취득 순서: Foundations → Copilot → Actions → Administration → Advanced Security → Agentic AI Developer
- 학습 Cycle: 용어 → 개념 → 공식문서 → 실습 → 문제풀이 → 오답 → 모의고사 → 시험 → 프로젝트
- 상태: PLANNED → READY → LEARNING → PRACTICING → REVIEWING → EXAM-READY → PASSED → CLEAR

## 문서 표기 원칙

- 핵심 기술 용어는 영어 원문과 한국어를 함께 표기합니다.
- 약어는 가능한 경우 Full Name을 먼저 제시합니다.
- 공식 자료는 URL과 학습 포인트 중심으로 정리하고 원문 전체를 복제하지 않습니다.
- 모든 실습은 목표, 사전지식, 따라하기, 검증, 문제해결 순서를 기본으로 합니다.
