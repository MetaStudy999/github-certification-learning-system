## 상태 체계

```text
Content Status
BOOTSTRAPPED → BUILDING → CONTENT-READY → MAINTENANCE

Learning Status
PLANNED → READY → LEARNING → PRACTICING → REVIEWING
→ EXAM-READY → PASSED → CLEAR
```

`CONTENT-READY`와 `EXAM-READY`를 구분합니다. 전자는 **학습 자료 구축 완료**, 후자는 **실제 학습자가 준비도 기준을 통과한 상태**입니다.

## 첫 학습 세션

현재 Repository 콘텐츠와 통합 운영 체계는 구축 완료 상태입니다. 실제 학습을 시작할 때 다음 순서를 사용합니다.

```text
001 Foundations README
→ 최신 GH-900 시험범위 확인
→ Terms / Concepts
→ 첫 Lab
→ Session 종료
→ 130-progress에 실제 결과 기록
```

학습을 실제로 시작한 시점에만 Foundations의 Learning Status를 `READY → LEARNING`으로 변경합니다.

## 문서 표기 원칙

- 핵심 기술 용어는 영어 원문과 한국어를 함께 표기합니다.
- 약어는 가능한 경우 Full Name을 먼저 제시합니다.
- 공식 자료는 URL과 학습 포인트 중심으로 정리하고 원문 전체를 복제하지 않습니다.
- 모든 실습은 목표, 사전지식, 따라하기, 검증, 문제해결 순서를 기본으로 합니다.
- 실제 시험 유출문제나 Brain Dump를 사용하지 않습니다.
- 제품과 시험 범위가 바뀔 수 있으므로 학습 시작·예약 전·응시 직전에 최신 공식 Study Guide를 다시 확인합니다.
