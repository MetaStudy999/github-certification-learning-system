## Status Semantics

```text
CONTENT-READY
= Repository의 학습 콘텐츠 구축 완료

READY / LEARNING / PRACTICING / REVIEWING
= 실제 학습자의 진행 상태

EXAM-READY
= 실제 학습자가 시험 준비도 Gate 통과

PASSED
= 자격시험 합격

CLEAR
= 자격시험 + 실습 + 프로젝트 + Evidence 완료
```
