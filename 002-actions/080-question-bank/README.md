# 080 Question Bank — GH-200 자체 문제은행

> 실제 시험 문항이나 Brain Dump를 복제하지 않고 공식 학습목표에 기반한 자체 문제만 사용합니다.

## 빠른 시작 (Quick Start, QS)

문제는 먼저 정답을 보지 않고 풉니다. 이후 **왜 정답인지 + 왜 다른 선택지는 덜 적절한지 + 관련 Lab**까지 확인합니다.

## Gate

- 1회차: **80/100 이상**
- 2회차: **85/100 이상**
- 오답 재시험: **90% 이상**

## Question Learning Cycle

```text
문제
→ 내 답
→ 정답
→ 선택 이유
→ 오답 선택지 분석
→ 관련 공식문서
→ 관련 Lab
→ 24시간 뒤 재시험
```

## 문제 설계 원칙

- YAML 문법만 묻지 않습니다.
- 권한·Runner·Reuse·Troubleshooting 상황을 포함합니다.
- `BEST`, `MOST appropriate`, `FIRST` 판단형 문제를 포함합니다.
- 실제 시험 문항 재현은 하지 않습니다.
