## Quick Start

1. Workflow, Event, Job, Step 구조를 이해합니다.
2. GitHub-hosted Runner와 Self-hosted Runner의 차이를 학습합니다.
3. Variables, Secrets, Context, Expressions를 실습합니다.
4. Matrix, Cache, Artifact, Reusable Workflow를 학습합니다.
5. 보안과 Enterprise 운영 관점까지 확장합니다.

- Workflow 작성 및 관리
- Event / Trigger
- Job / Step / Runner

- Matrix / Cache / Artifact
- Reusable Workflow / Composite Action
- Automation Security
