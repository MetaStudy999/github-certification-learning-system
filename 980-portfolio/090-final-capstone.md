## 목표

## Target Architecture

```text
Issue / Requirement
        ↓
GitHub Repository / Branch / Pull Request
        ↓
GitHub Copilot / AI-Assisted Development
        ↓
GitHub Actions CI/CD
        ↓
Enterprise Identity / Policy / Governance
        ↓
Secret Protection / Supply Chain / Code Security
        ↓
Agentic AI
  ├─ Controlled Tools / MCP
  ├─ State / Checkpoint
  ├─ Evaluation
  ├─ Guardrails
  └─ Human Review
        ↓
Audit / Evidence / Portfolio
```
