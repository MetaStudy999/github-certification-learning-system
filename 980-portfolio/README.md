# 980 Portfolio — 통합 포트폴리오 Control Tower

6개 자격증의 학습 결과를 **자격증 배지 → 실습 → 프로젝트 → Evidence → 누적 Capstone**으로 연결합니다.

## 빠른 시작 (Quick Start, QS)

1. [`010-portfolio-map.md`](./010-portfolio-map.md)에서 자격증별 대표 프로젝트를 확인합니다.
2. [`020-evidence-matrix.md`](./020-evidence-matrix.md)에서 포트폴리오에 필요한 증거를 추적합니다.
3. 각 과정의 `100-projects/`와 `150-evidence/`를 연결합니다.
4. 6개 과정을 통합한 [`090-final-capstone.md`](./090-final-capstone.md)를 최종 목표로 사용합니다.

## Cumulative Capability 흐름 (Cumulative Capability Flow, CCF)

```text
001 Foundations
Repository / Branch / Issue / PR / Review
        ↓
002 Actions
CI/CD / Workflow / Runner / Reuse / Security
        ↓
003 Copilot
AI-Assisted Development / Prompt / Context / Review
        ↓
004 Administration
Enterprise / Identity / Permission / Policy / Audit
        ↓
005 Advanced Security
Secret / Supply Chain / CodeQL / Security Operations
        ↓
006 Agentic AI Developer
Agent / Tool / MCP / State / Evaluation / Guardrails
        ↓
Final Capstone
AI-Native Secure Software Development Platform
```

## Portfolio Unit

각 과정은 다음 묶음을 하나의 포트폴리오 단위로 봅니다.

```text
Credential
+ Project
+ Architecture / Design
+ Verification Evidence
+ Reflection
```

## 목표

최종 목표는 자격증 6개 보유 자체가 아니라, **GitHub 기반 AI-Native Secure Software Development 역량을 재현 가능한 산출물로 보여주는 것**입니다.
